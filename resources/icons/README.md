# 图标放在这里（美术 / 美工专用）

> 这个文件夹是**所有游戏图标的唯一来源**。你（美术）以后加图标、换图标，**只动这个文件夹**，不用碰任何代码。

## 怎么加一个新图标
1. 准备好图片（建议 `PNG`，透明背景；也支持 `webp` / `svg` / `jpg`）。
2. 按"分类"丢进对应子文件夹，文件名用英文、见名知意：
   ```
   resources/icons/
   ├─ items/        物品图标（丹药、武器、材料…）
   │   ├─ heal_pill.png
   │   └─ iron_sword.png
   ├─ skills/       武学 / 技能图标
   │   └─ fire_sword.png
   ├─ npc/          NPC 头像
   │   └─ su_waner.png
   ├─ status/       状态（增益/减益）图标
   │   └─ burn.png
   ├─ ui/           界面按钮 / 装饰图标（菜单、背包、地图…）
   │   └─ menu.png
   └─ _sample/      示例（sample_heart.png，可删）
   ```
3. 告诉策划 / 程序这个图标的"名字"，例如 `skills/fire_sword`（**不带扩展名、带子文件夹**）。
   程序会在物品/技能/NPC 的配置里写 `"icon": "skills/fire_sword"`，游戏自动显示。

## 怎么"替换"一个旧图标
- 直接**用同名文件覆盖**即可（例如新的 `items/heal_pill.png` 盖掉旧的）。游戏里立刻生效，不用改任何配置。

## 图片建议
- 尺寸：正方形，建议 **64×64 或 128×128**（2 的幂最好），放大缩小都清晰。
- 透明背景（PNG 带 alpha），边缘干净。
- 不要带中午文件名；名字用英文、下划线分隔。

## 找不到图标会怎样？
- 游戏不会崩。缺图标的地方会显示一个**品红色棋盘占位图**，提醒"这里还缺一张图"。
- 所以你随时可以只丢一部分图，剩下的先占位，不影响程序跑。

## 给程序看的（不用管，了解即可）
- 图标解析规则在 `scenes/ui/icon_registry.gd`，统一入口是 `UIManager.get_icon(<名字>)`。
- 详细规范见 `docs/图标替换与美术接入规范.md`。
