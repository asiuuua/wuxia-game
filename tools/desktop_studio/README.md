# 内容工作室 · 桌面版（NPC / 剧情 / 欢庆 / 登录界面 编辑器）

给非程序员用的本地工具：双击即用，全程填表改游戏数据，**零代码**。
它与 Godot 里的「内容工作室」编辑器插件读写的**同一批文件**，二选一即可。

---

## 一、怎么打开

**方式 A（推荐，最简单）：双击 `studio_launcher.bat`**
- 会自动启动本地服务并打开浏览器到 `http://127.0.0.1:8765/`。
- 关闭：直接关掉弹出的 Python 黑窗口。

**方式 B：命令行**
```
python studio_server.py
```
然后浏览器打开 `http://127.0.0.1:8765/`。

> 本机 Python 路径默认指向 WorkBuddy 托管的
> `C:\Users\Administrator\.workbuddy\binaries\python\versions\3.13.12\python.exe`，
> 若你换机器，编辑 `.bat` 里的 `PY` 变量或保证 `python` 在 PATH 即可。

**想要一个真正的 `.exe`（不依赖 Python）？**
用 PyInstaller 打包一次即可（需联网装一次）：
```
python -m pip install pyinstaller
pyinstaller --onefile --name 工作室专业调教 studio_server.py
```
生成的 `dist/工作室专业调教.exe` 双击即用。已打包的话直接发你 `工作室专业调教.exe` 即可。

## 二、标签页都能干啥

| 标签页 | 作用 | 改的是哪个文件 |
|---|---|---|
| **NPC 数据** | 增删改 NPC：名称、**地图上坐标(pos_x/pos_y，支持画布点选定位)**、立绘、头像、对话id、任务id、战斗id，以及**半身立绘（动态可一键导入）** | `data/configs/npcs/town_npcs.json` |
| **剧情对话** | 建对话 → 建/改台词（说话人、文本、下一句、触发事件） | `dialogs/_index.json` + `shards/*.json` |
| **欢庆模块** | 选/绑 NPC → 填 CG 媒体、音乐、台词 | `data/configs/bond/celebrations.json` |
| **登录界面** | 一键换登录主界面大背景图、改各按钮文字（简/繁/英）、查看版本文字、为各按钮配背景图（**可实时预览 + 一键清除回退默认**） | `assets/ui/main_menu_bg.png` + `data/configs/localization/strings.csv` + `data/configs/ui/login_button_bg.json` |
| **预加载界面** | **自由拖拽可视化排版**：直接拖动进度条 / 进度百分比 / 提示语 / 版本号 4 个元素到任意位置，进度条还能调宽度，点「保存布局」即写入游戏 | `data/configs/ui/loading_layout.json` |
| **回收站 / 日志 / 设置** | 恢复误删、查操作记录、改工程根目录与保险天数 | `safety_data/`（本地，勿提交） |

**⏳ 预加载界面（加载页）怎么调（重要）：**
游戏启动时那张加载页上的 4 个元素，位置全部可以在这里**用鼠标拖**：
- 打开「预加载界面」标签页，画布里那 4 个东西（进度条 / `0%` 文字 / 提示语 / 版本号）**直接按住拖**就行；
- 进度条长度用下面的「进度条宽度」滑块调（10%~100%）；
- 点「保存布局」写入 `data/configs/ui/loading_layout.json`，**下次启动游戏生效**；
- 点「恢复默认」回到原始排版。
- 存的坐标是**窗口比例（0~1）**，不是像素，所以 PC、带鱼屏、手机都会自动适配，不会跑位。

**📍 NPC 坐标参考栏：**
编辑 NPC 时上方那块「参考：现有 NPC 坐标」显示格式为 `唯一ID · 名称 · (x, y)`，**没填名称的会显示 `null`**，一眼能看出是谁。
- 点左侧列表里某一项 → 参考栏**只显示这一条**（方便对照）；
- 点「🎲 随机抽 5 个」→ 随机抽 5 条当参考样本；
- 点「显示全部」→ 恢复列出全部；
- 点任意一条即可把它的坐标抄进下方表单。

**NPC 是怎么"上地图"的（重要）：**
NPC **不是随机摆放**——游戏城镇场景会自动读取 `town_npcs.json`，按每条的 `pos_x / pos_y` 把 NPC **生成到对应坐标**。
所以你只管在工具里填数据、保存，按 F5 跑游戏，NPC 就出现在地图上，**不用写任何实例化代码**。
- 不知道坐标填多少？两招：① 用「🗺 地图坐标预览」画布，**直接点一下地图**就把 NPC 放到那个点（红点=其它 NPC，黄点=当前编辑的）；② 点「参考：现有 NPC 坐标」把某个老 NPC 的坐标抄过来再微调。
- 立绘 `sprite` 先填 `res://assets/characters/player.png` 占位，之后换成你的美术文件。

**🖼 半身立绘（动态可一键导入，已合并进 NPC 编辑区）：**
在「NPC 数据」标签页的编辑区里，有一块「半身立绘」专门用来给这个 NPC 配立绘，**无需碰游戏代码**：
- 选「类型」：**静态图片** / **帧动画（上传 ZIP 多帧）** / **Spine·SK2D 骨骼（上传 ZIP）**。
- 点「⏫ 一键导入」即把文件存到 `assets/characters/half_body/`（静态=`<id>.png`；帧动画=`<id>_frames/`；Spine=`<id>_spine/`），并自动把 `half_body_portrait` / `portrait_type` / `portrait_frames` 等字段写进该 NPC 记录。
- 「清除立绘」可把立绘字段清回空（游戏会回退到按 id 生成的占位图）。
- 游戏侧已预留动态播放接口；当前先显示占位静态图，后续接入帧动画/Spine 即生效。

**唯一 ID 的"防误改"四重保险（很重要）：**
- **① 默认锁定**：编辑已有 NPC 时，`id` 输入框是锁定的，手滑也改不到。
- **② 改 ID 需二次确认**：要点「🔒 已锁定（点此修改）」→ 弹两次确认框才能解锁改名；改名会走"删旧+建新"逻辑，不会产生重复记录，旧记录自动进回收站。
- **③ 一键回退**：改名前可「↩ 回退原ID」还原输入框；改名保存后还能「↩ 撤销重命名」直接回滚。
- **④ 引用 ID 防误改**：对话 id / 任务 id / 战斗 id 一旦被改动，会弹确认框，点取消即还原；保存时还会检查"对话 id 是否存在于剧情表里"，不存在会提醒。

## 三、登录界面标签页（换皮不用写代码）

> 覆盖范围：登录主界面（主菜单）以及它打开的窗口（难度选择 / 读档 / 设置等）共用的资源。
> 绝大多数改动走**数据文件**，进游戏即生效。唯独「背景布局」一项，你选择了方案 B——小改 `UIBackground.gd` 让游戏运行时读取 `data/configs/ui/login_bg_layout.json`（约 20 行、已过双闸门），从而能按窗口大小实时自适应；其余文案 / 大背景图替换仍是纯数据改动。

打开「登录界面」标签页后有五块：

1. **🖼 大背景图**
   - 选一张图 → 点「替换大背景图」即可。
   - 这张图被**主菜单 / 加载界面 / 读档界面三个场景共用**，换一次三处一起变。
   - 文件落点：`assets/ui/main_menu_bg.jpg`（替换前自动备份到 `safety_data/backups/`）。

2. **🔤 按钮文字对照表**
   - 把登录界面上每个按钮的简体 / 繁体 / 英文 三语文本列成表格，直接改、点「保存」即可。
   - 覆盖：开始新的旅程、继续江湖路、读取旧梦、游戏设置、江湖图鉴、退出江湖，以及底部的「设置」「语言」、制作组名。
   - 文件落点：`data/configs/localization/strings.csv`（游戏用 `tr()` 读取，改完进游戏即生效）。
   - 表格里「点击打开」一列标了该按钮在游戏里会打开哪个窗口，方便你核对。

3. **🏷 版本文字**
   - 只读显示当前版本号（如 `v0.5.0 Build 20250827`，写在 `MainMenu.gd` 里）。
   - 因你选择不动游戏代码，这里不可直接编辑；哪天想改版本号告诉我，我改一行并跑双闸门保证不出错。

4. **🎴 各按钮背景图（进阶）**
   - 给主菜单 6 个大按钮各自配一张背景图（按按钮位置放好图，导入即替换对应按钮的背景样式）。
   - 文件落点：`assets/ui/main_menu_btn/<按钮id>.png`，并在 `data/configs/ui/login_button_bg.json` 记录映射。
   - ⚠️ 当前游戏代码**尚未读取**这张映射表，所以配了图要在游戏里真正显示，需要我在 `MainMenu.gd` 加几行读取并套用到按钮（低风险，约十几行，会跑双闸门）。你点头我再做。

5. **🎛 背景布局（实时预览）**
   - 解决「换了背景图还是不满意」的核心诉求：游戏原来写死等比不裁切 + 一块写死的绿渐变垫底，比例不对就露绿缝。
   - 现在可在这里选布局预设（**铺满裁切 Cover（推荐）/ 完整显示 Contain / 拉伸填满 / 平铺 / 居中 / 等比居中**），下方**实时预览**会按你当前背景图在 PC 16:9 / 带鱼屏 21:9 / iPad 4:3 / 手机 19.5:9 四种比例下同时显示效果。
   - 还能调「暗化强度」（保证菜单文字可读）、「自动取图边色填缝」（用你这张图自己的边缘色补缝，彻底告别绿渐变）、「落叶粒子」开关。
   - 点「保存布局」即写入 `data/configs/ui/login_bg_layout.json`，游戏内 `UIBackground` 运行时读取，**任意窗口比例都自动适配、无黑边**（大厂同款做法：背景 cover + 菜单落安全区）。
   - 默认值：`keep_aspect_covered`（铺满裁切）、暗化 55%、自动取边色开、落叶开。

## 四、保险机制（防误删 / 防误改）

默认开启，专门对付"手滑删错 / 改错"：

1. **删除不真删**：任何删除（NPC / 台词 / 对话 / 欢庆）在保险模式下只把内容挪进**回收站**，并写日志。
   回收站里可随时「恢复」或「彻底删除」。
2. **改之前先备份**：每次保存/覆盖文件前，自动在 `safety_data/backups/` 留一份带时间戳的副本，
   即使误改也能手动找回旧版本。
3. **操作日志**：所有动作记录在 `safety_data/studio_log.jsonl`，在「操作日志」标签页可查。
4. **到期自动清空**：回收站项目保留「设置」里的天数（默认 30 天），到期由程序自动清理，不占空间。

想关掉保险（删除即真删）？到「设置」把保险模式切到"关"。

## 五、目录结构

```
tools/desktop_studio/
├─ studio_launcher.bat   # 双击启动
├─ studio_server.py      # 本地 Web 服务（标准库，零依赖）
├─ studio_core.py        # 核心逻辑：读写 + 保险/日志/回收站
├─ index.html            # 浏览器界面
└─ safety_data/          # 自动生成：回收站 / 备份 / 日志 / 设置（已 gitignore，勿提交）
```

## 六、注意

- 编辑时**不要同时用 Godot 跑着游戏**改同一份文件，避免互相覆盖。
- 改完数据后，进 Godot 按 F5 跑游戏查看效果。
- 工程根目录在「设置」里可改；默认 `D:/武侠游戏`。
