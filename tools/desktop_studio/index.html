📐 多分辨率变体（按屏幕自动挑图，任务 #47） 背景

可为同一张背景准备几档不同分辨率：游戏启动时按窗口宽度自动挑最合适的一档—— 4K 屏吃 4K 图不糊，1080p 屏也不必白扛一张 4K 图的内存。没配变体就继续用主图，零影响。
生效宽度 ≥图片尺寸体积
常用档位：1080p 填 0，2K 填 1921，4K 填 3000。档位名只用于文件名（如 main_menu_bg_2k.png），同一生效宽度重复上传会覆盖旧档。

🪶 按钮悬停浮动（上浮高度 / 左右位移） 布局

调节鼠标悬停时图标与文字一起浮动的幅度：上浮高度是向上飘多少像素；左右位移是整体往哪边轻移多少像素（滑到最左=向左移、中间=不左右移、最右=向右移）。调整后写 data/configs/ui/main_menu_assets.json 的 hover_shift_x / hover_shift_y，下次进主菜单生效。

🎴 各按钮背景图（高级） 资源

给每个主菜单按钮单独换背景图。游戏代码现在已读取此映射（data/configs/ui/login_button_bg.json），上传图片后下次进主菜单即生效；图会铺满按钮并以「cover」方式裁切，外加一层轻压暗保证文字可读。 注意：按钮是 280×44 的横条，请上传横版图，竖图会被裁得只剩中间一小条。
图片内容与扩展名不符时（如 JPEG 存成 .png），Godot 会导入失败、按钮背景静默消失。点此自动按真实格式改名并更新映射，不丢图。
