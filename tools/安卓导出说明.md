# 安卓导出说明（18图 RH-3 / Phase4 实测前置）

`export_presets.cfg` 已含 **Android（ARM64）** 预设占位：包名 `com.asiuuua.wuxiajianghu`、min/target SDK 留空（装好构建模板后按需填）、keystore 四字段留空。

## 你需要自己做的（AI 不代管密钥）

1. Godot 编辑器 → 编辑器设置 → 导出 → Android：填 Android SDK 路径与调试密钥库（Godot 可自动生成 debug keystore）。
2. 正式发布 keystore：`keytool -genkeypair -v -keystore wuxia_release.keystore -alias wuxia -keyalg RSA -validity 10000`（自己设密码，**丢了无法再更新应用**）。
3. 把 keystore 路径/别名/密码填进 `export_presets.cfg` 的 `[preset.1.options]` keystore/release 三字段（或导出对话框里填）。
4. 实测出包归 18 图 Phase4（开放问题 RH-4：触摸、返回键、权限、emulate_mouse 决策 checklist）。

产物命名冻结：`wuxiajianghu_{版本}_{build_id}_android.apk`（build_release.py 自动执行）。
