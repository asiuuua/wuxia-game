# 剧情导入器 · 零基础使用说明

你不需要会写代码。只要会填 Excel 表格，就能把**自己写的剧情、人物、战斗、物品**塞进游戏。

---

## 一、它能帮你把什么连起来？

游戏里一条完整的"剧情链"是这样跑的（已经帮你接好了）：

```
你填的 NPC（人物）
   └─ 他说的对话
   └─ 他给的任务（任务模板）
        └─ 任务要你打哪场战斗（战斗模板）
             └─ 战斗里有哪些敌人（敌人模板）
                  └─ 敌人掉什么 / 任务奖什么（物品模板）
```

你只要按下面 5 张表填，剩下的串联**全自动**。

---

## 二、操作步骤（照做就行）

1. 打开 `tools/story_import/` 文件夹。
2. 用 **Excel / WPS / 记事本** 打开这 5 个 `.csv` 文件（中文表头，一列一项）：
   - `人物模板.csv` —— 谁、在哪、说什么、给什么任务/战斗
   - `任务模板.csv` —— 任务名、打哪场战斗、给多少经验/银两/物品
   - `战斗模板.csv` —— 战斗名、放哪几个敌人
   - `敌人模板.csv` —— 敌人属性、掉什么
   - `物品模板.csv` —— 自定义道具（任务奖励、敌人掉落都在这填）
3. **删掉里面 `demo_` 开头的示例行**，换成你自己的内容（id 自己起，建议英文+数字，如 `npc_li_village`）。
4. 填的时候记住一条铁律：**上下表的 id 要对上**。
   - 人物表的"任务id" = 任务表的"任务id"
   - 人物表的"战斗id" = 战斗表的"战斗id"
   - 任务表的"目标战斗id" = 战斗表的"战斗id"
   - 战斗表的"敌人id1" = 敌人表的"敌人id"
   - 任务/敌人的"奖励物品id""掉落物品id" = 物品表的"物品id"
5. **双击 `run.bat`**（或在文件夹里 Shift+右键"打开终端"跑 `python convert.py`）。
6. 看到"导入完成"就成功了。用 Godot 打开工程 → 进城镇 → 走过去和你的 NPC 对话，任务/战斗就触发了。

---

## 三、安全须知（不会搞坏工程）

- **按 id 合并**：已经存在的 id 会自动跳过，不会覆盖、不会重复。
- **可反复跑**：改完表再双击一次即可，只加新的。
- **想撤销**：把模板里你加的行删掉、重跑没用（因为 id 还在游戏数据里）。要彻底删，去 `data/configs/` 下对应 json 里删掉你那段即可（有 id 好找）。
- **只动数据，不动代码**：它只改 `data/configs/` 里的 JSON，永远不碰 `.gd` 脚本。

## 四、各表字段速查

### 人物模板.csv
| 列 | 填什么 | 例子 |
|---|---|---|
| npc_id | 人物唯一id | npc_beggar |
| 名字 | 显示名 | 村口老乞丐 |
| x坐标/y坐标 | 在城镇里的位置(0~640,0~360) | 420 / 260 |
| 立绘路径/头像路径 | 图片路径(没有就留空) | res://assets/... |
| 对话1说话人 / 对话1内容 | 第1句谁说、说啥 | 村口老乞丐 / 少侠... |
| …对话2~4 | 最多4句 | |
| 任务id | 对话结束后给的任务 | quest_jade |
| 战斗id | 直接开打的战斗(没有留空) | battle_dog |

### 任务模板.csv
类型填 `main`(主线) 或 `side`(支线)；目标战斗id 填你要打的战斗；奖励物品id/数量 不填就不给。

### 战斗模板.csv
敌人id1~3 填敌人表里定义的敌人，最多3个。

### 敌人模板.csv
血量/攻击/速度 填数字；武学id1 留空即可；掉落物品id1/数量1 不填就不掉。

### 物品模板.csv
类型填：`weapon`(武器) / `pill`(丹药) / `material`(材料·任务道具用它) / `armor`(护甲) / `accessory`(饰品)。
- 武器填"攻击"
- 丹药填"治疗血量/治疗内力"
- 护甲填"防御/血量/内力"
- 材料留空就行

## 五、进阶（可选）

- 多张地图/多个城镇：现在 NPC 都刷在 `town_001`。要做新地图，让 AI 帮你加一个场景并在里面 `_spawn_npcs` 同理接 `ConfigManager.get_npc`。
- 分支对话、多结局、剧情 CG：属于表现层，先填表把主线跑通，再让 AI 在 `DialogOverlay` / 剧情系统上扩展。
- 立绘/头像图片：把图放进 `assets/characters/`，路径填进"立绘路径/头像路径"即可显示。
