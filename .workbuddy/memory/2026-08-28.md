8. **CSV import UID 警告**：`tools/story_import/*.csv` 被 Godot 自动识别为 translation resource 生成一堆 `.translation` 子文件 + UID duplicate 警告。**`project.godot [scan] exclude_folders/exclude_extensions` 在 4.7.2 不生效**。最终方案：**`tools/story_import/.gdignore`**（空文件即可）让 Godot 整个跳过该目录。

9. **连带修的两个潜在 bug**（editor reload 比 CLI 严格）：① `SaveLoadScreen.gd:125` 8 处使用 `_list_container` 但 0 处声明，补 `var _list_container: VBoxContainer = null`；② `tests/ui/m5_smoke.gd:27` 用 `TransitionManager.transition_to(...)` 但 `transition_manager.gd` 文件存在却没注册 autoload，加进 `project.godot [autoload]` 段。

**结果**：warnings **57 → 0**，editor 模式 25 秒运行零 WARNING/ERROR/SCRIPT。临时探测脚本 `tmp_enum_probe.gd` 已清。

**经验**：
- **API 改了别硬扛**：先用临时探测脚本（`get_property_list()` 看 hint 字符串）确认 Godot 当前 API 再改。
- **CLI 不报的 bug editor 才会报**：未声明 var、未注册 autoload 这类问题，`--headless --quit` 放过，editor reload 严格报。
- **`.gdignore` 比 `project.godot [scan]` 稳**——前者必生效，后者 4.7.2 不认。
