# 资产管线（AI 生成 + 自修）

纯个人开发，美术资源按「规格表 → 生成 → 自修 → 导入」流程生产，保证风格统一、可控。

## 1. 先定规格表（每个资产类别一张表）
- **分辨率**：角色精灵 256×256 或 512×512；场景贴图 1024。
- **调色板**：固定主色（如墨黑/朱红/靛青），避免五彩斑斓。
- **风格参考图**：找 2–3 张定调（如《今古群侠传》截图、某 LoRA 样张）。
- **帧数**：待机 4 帧、行走 6 帧、攻击 8 帧（2D 精灵逐帧动画）。

## 2. 生成
- **2D 角色精灵**：AI 出图（固定 LoRA + 固定 seed/参考图）→ 出多帧 → 修。
- **3D 场景**：优先买底料（Itch / Godot 商店 / Unity 资源店等距 3D 场景包），AI 仅补细节或手改。

## 3. 自修（一致性关键）
- 用 PS / Krita / Blender 统一描边、调色、修手。
- 多角色共用同一套笔刷与调色板，避免「千人千面」。

## 4. 导入 Godot
- 精灵帧：导入为 `SpriteFrames`，命名 `char_角色名_动作`。
- 3D 模型：`assets/models/`，场景地块 `assets/environments/`。
- 角色在 3D 场景中以 `Sprite3D`（billboard）呈现，朝向相机。

## 5. 命名规范
```
assets/
├── characters/   角色精灵帧（char_xxx_idle / _walk / _attack）
├── environments/ 3D 地块、建筑、植被
├── ui/           HUD、图标、按钮
├── icons/        技能/物品图标
└── audio/        音乐、音效（Phase 2）
```

## 6. 版权提醒
单机离线风险低；若要上架 Steam / 移动商店，须确认生成与购买资产的授权范围。
