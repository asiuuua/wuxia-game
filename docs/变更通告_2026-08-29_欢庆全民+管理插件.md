# 变更通告 · 欢庆全民化 + 管理插件（2026-08-29）

> 需求：① 所有「可结缘」NPC，只要好感度满了，都能使用欢庆功能（不止已婚配偶）；② 给非技术作者一个编辑器插件，能一键导入/修改欢庆的台词·图片·视频·音乐，并预留 NPC 一键绑定接口，方便后续对接更多 NPC。

## 一、改动文件清单

### 结缘窗口主权（逻辑/UI）
- `services/bond/romance_service.gd`
  - `begin_celebration` 门槛从「强制已婚配偶」改为 `can_celebrate(npc_id)`（= 可结缘 `is_romanceable` + 好感满 `>= propose_affection`）。好感满的非配偶也能欢庆。
  - **配额存储解耦**：从 `spouses[npc_id]["celebration"]` 移到独立字典 `celebration_quotas[npc_id]`。修复原 bug——非配偶欢庆时会误把 NPC 写进 `spouses` 配偶列表污染「配偶」区。
  - `cg_id` 返回 `npc_id`（原 `"default"`），`CelebrationOverlay` 据此按 per-NPC 内容查找、缺省回退 `default`。
  - 受孕仍**仅限配偶**（非配偶好感满也能欢庆，但不受孕）。
  - 新增 `can_celebrate(npc_id)` / `_is_affection_full(npc_id)` 查询；`save()`/`load()` 纳入 `celebration_quotas`。
- `scenes/ui/screens/bond_romance/BondRomanceScreen.gd`
  - 「五、可发展」区：对 `is_romanceable` 且 `can_celebrate(npc_id)` 为真（好感满、非配偶）的候选 NPC，增加「欢庆(n)」按钮（`_on_celebration` 已支持 per-NPC cg_id）。
  - 「一、配偶」区：欢庆按钮显示当日剩余次数「欢庆(n)」。
- `data/configs/bond/celebrations.json`：`_doc` 升级，说明任意以 `npc_id` 为顶层键的项是该 NPC 专属覆盖（结构同 `default` 的 `cg`/`end`），`CelebrationOverlay` 按 `cg_id=npc_id` 查找、回退 `default`。

### 编辑器插件（小白友好 · 一键导入/绑定）
- `addons/celebration_manager/plugin.cfg`：插件清单。
- `addons/celebration_manager/plugin.gd`（`@tool extends EditorPlugin`，**无 class_name**）：在编辑器左上方坞挂上面板。
- `addons/celebration_manager/celebration_manager_dock.gd`（`@tool extends Control`，**无 class_name**）：面板本体。功能：
  1. **NPC 选择**：下拉读取 `relations.json` 中所有 `is_romanceable` 的 NPC；「刷新列表」重扫；自由输入 id + 「绑定新NPC/绑定」= NPC 一键绑定接口（若 id 已在 celebrations.json 也纳入）。
  2. **一键导入 CG**：「导入CG(视频/图片)…」用 `EditorFileDialog` 选文件 → 自动复制到 `res://resources/cg/<npc_id>/` → 自动识别类型（ogv/webm/mp4→video，其余→image）并填路径。
  3. **一键导入音乐**：「导入音乐…」同理复制到同目录，填 `bgm`。
  4. **一键导入台词**：「导入台词.txt」读文本按行填入欢庆台词。
  5. **编辑**：媒体类型(无/图片/视频)、欢庆台词(每行一条)、结束内容台词。
  6. **保存**：合并写回 `celebrations.json`（按 `npc_id` 分键，保留 `default`/`over_limit`/其它 NPC）；「删除该NPC」移除该键；「预览JSON」打印当前条目。

### 工程配置（纯追加）
- `project.godot`：追加 `[editor_plugins]` + `enabled=PackedStringArray("celebration_manager")` 自动启用插件。
- `tests/unit/test_romance_service.gd`：新增 3 项（好感满非配偶可欢庆且不污染配偶/不受孕 / 好感未满拦截 / 不可结缘拦截）。

> ⚠️ 插件两脚本均无 `class_name` 且为编辑器专用（`extends EditorPlugin`/@tool），游戏运行时**不会加载**，不影响双闸门与导出包。

## 三、作者怎么用（小白向）
1. 用 Godot 打开项目（编辑器），左上坞已出现「欢庆内容管理器」面板（若没有，到 `Project Settings → Plugins` 把 `Celebration Manager` 设为启用）。
2. 下拉选一个可结缘 NPC；或直接在输入框填新 NPC 的 id 点「绑定」。
3. 点「导入CG(视频/图片)…」选你的视频/图片，「导入音乐…」选 BGM，「导入台词.txt」选台词；也可手填。
4. 点「保存」→ 自动写进 `celebrations.json` 的对应 NPC 键。游戏内该 NPC 好感满后欢庆即播这段内容。
5. 不填媒体只填台词也行（媒体类型选 none）。CG 时长仍由 `CelebrationOverlay` 自动截断到 10 秒。

## 四、待确认 / 后续
