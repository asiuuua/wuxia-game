## 二、核心设计

### 加载分发（UIManager.open_screen）
```gdscript
var path: String = String(entry.get("path", ""))
if path.ends_with(".tscn"):
    var packed: PackedScene = load(path) as PackedScene
    screen = packed.instantiate() as Control   # B 路线：复合控件场景
else:
    var script: Script = load(path) as Script
    screen = script.new() as Control           # 过渡期：老界面脚本
```
- `.tscn` 与 `.gd` 在装配层完全等价：`screen.name = screen_name`、`_on_open(init_data)`、`canvas.add_child`、`cache` 缓存模式、淡入转场逻辑**全部复用**，无需为 `.tscn` 另写分支。
- 过渡期双格式并存，每转一屏即保双闸门绿，项目始终可跑。

### 背包屏结构/数据分离
- 静态结构（节点树、层级、容器、列数）进 `.tscn` → 美术可可视化编辑。
- 文本/配色（`tr()`、UIPalette 取色）与动态填充（按库存数据建/复用槽位）留脚本——这是 B 路线的"状态/数据驱动"本质，结构在场景、数据与行为在代码。
- 玻璃面板皮肤暂沿用 `UICenterUtils.apply_glass_style`（后续随 UISkin 纹理/九宫格层一并替换，不阻塞本次）。
