# 变更通告：内容工作室（剧情/文本创作集合插件）

日期：2026-08-30

## 目的
为后续「剧情和文本工作」做一个零代码的可视化编辑器，把三张常用数据表集中到一个编辑器坞里：

1. **NPC 数据表** —— `data/configs/npcs/town_npcs.json`
2. **剧情/对话表** —— `data/configs/npcs/dialogs/_index.json` + `shards/*.json`
3. **欢庆模块** —— `data/configs/bond/celebrations.json`（复用原有 celebration_manager 面板）

## 怎么用（小白向）
- 打开 Godot → 看编辑器**左侧坞**多了一个「**内容工作室**」→ 它有三个标签页：`NPC数据表` / `剧情对话表` / `欢庆模块`。
- 万一没看到坞：菜单 `项目设置 → 插件`，勾选 **Content Studio**。
- **NPC数据表**：左边选一个 NPC，右边直接改名称/立绘/对话id/任务id 等，点「保存」就写回 `town_npcs.json`（不用碰代码）。
- **剧情对话表**：左边选一段对话 → 中间选某一句台词 → 右边改说话人/台词文本/下一句 → 点「保存台词」写回对应分片文件；「新建对话」会自动建一个分片文件并登记进 `_index.json`。
- **欢庆模块**：和原来一模一样（选 NPC → 导入 CG/音乐/台词 → 保存）。

## 这次改了什么
- 新增 `addons/content_studio/`：`plugin.gd`、`npc_panel.gd`、`story_panel.gd`、`plugin.cfg`。
- `project.godot` 的 `[editor_plugins]` 启用项改成 `content_studio`。**欢庆模块改为内嵌进这个集合**（不再单独占一个坞，避免你看到两个重复的欢庆面板）。

## 影响与注意
- 纯编辑器插件，不进游戏运行时；双闸门验证：`GATE1 CLEAN`、`GATE2 通过 43·失败 0`，零影响。
- 欢庆功能本身**完全没有改动**，只是入口合并到「内容工作室 → 欢庆模块」标签页。
- 想恢复独立的欢庆坞：`项目设置 → 插件 → 勾选 Celebration Manager` 即可（两者可并存，只是会同时出现两个坞）。
- **任务(quest)表暂未纳入**本集合；如果后续你也想在这里改任务，说一声我再加一个标签页。
