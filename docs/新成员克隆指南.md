# 新成员克隆指南（武侠江湖 · Godot 4.7.2 单机 CRPG）

> 本仓库代码托管在 **GitHub**（`origin`），4 个大图走 **Git LFS**。照下面做，10 分钟内能跑起来。
> 适用对象：新加入开发的成员（含你授权的 AI 窗口）。

---

## 0. 一句话流程

装 Git(+LFS) → 装 Godot 4.7.2 → 配 SSH 公钥 → 克隆（LFS 自动拉大图）→ 用 Godot 打开。

---

## 1. 安装必要软件

### 1.1 Git（必须，且要带 Git LFS）
- 下载 Git for Windows：https://git-scm.com/download/win （安装时勾选 **Git LFS**；或直接装 Git for Windows 2.40+，默认不含 LFS，需额外装）。
- 单独装 Git LFS：https://git-lfs.com → 下载 Windows 安装包 → 装完跑一次 `git lfs install`。
- 验证：
  ```bash
  git --version
  git lfs version      # 应显示类似 git-lfs/3.x.x
  ```

### 1.2 Godot 4.7.2（必须，版本不对会打不开工程）
- 本工程 `project.godot` 声明 `config/features="4.7"`，**只能用 4.7.x**。
- 下载 4.7.2-stable（Windows 64 位）：https://godotengine.org/download/4.7.2/ → 选 **Standard（或 .NET 无关，纯 GDScript 用 Standard 即可）**。
- 把 `Godot_v4.7.2-stable_win64.exe` 放到任意目录（如 `D:\tools\`），**双击它**来打开工程。

> ⚠️ 本机已有的 Godot 在 `C:\Users\Administrator\.workbuddy\binaries\godot\Godot_v4.7.2-stable_win64.exe`，新成员请自己下载一份，不要依赖这台机器。

## 2. 拿到 GitHub 仓库访问权

仓库是 **私有（Private）** 时需要被加为协作者；公开则无需。

1. 让管理员（asiuuua）在 GitHub 仓库 → **Settings → Collaborators** 把你账号加进去（或把仓库改 Public）。
2. 你本地生成 SSH 密钥并把自己的公钥加到 GitHub：
   ```bash
   ssh-keygen -t ed25519 -C "你的邮箱或昵称" -N ""
   # 公钥在 ~/.ssh/id_ed25519.pub，用记事本打开复制整行
   ```
3. GitHub 右上角头像 → **Settings → SSH and GPG keys → New SSH key** → 粘贴公钥 → Add。
4. 测试连通：
   ```bash
   ssh -T git@github.com
   # 看到 “Hi 你的用户名! You've successfully authenticated” 即成功
   ```

## 3. 克隆仓库（大图经 LFS 自动下载）

```bash
# 选一个工作目录，例如 D:\
cd /d/

# 克隆（SSH 方式，LFS 文件会在 checkout 时自动拉真实大图）
git clone git@github.com:asiuuua/wuxia-game.git

# 进入工程
cd wuxia-game

# 确认 4 个大图已拉成真实文件（不是指针文本）
git lfs ls-files          # 4 个文件应带 * 号，表示本地已有真实对象
# 抽查一个文件头应为 PNG：
head -c 8 assets/ui/main_menu_bg.png | xxd
# 应显示 89504e47（= PNG 真实文件头）
```

> 如果 `git lfs ls-files` 里文件**没有 `*`**、或文件头是 `version https://git-lfs...`，说明大图没拉下来：
> ```bash
> git lfs pull          # 手动补拉 LFS 对象
> ```

## 4. 用 Godot 打开并验证

1. 双击 **Godot 4.7.2** 启动器 → 点 **Import（导入）** → 选择 `D:\wuxia-game\project.godot` → **Import & Edit**。
2. 首次打开 Godot 会重建 `.godot` 缓存（几秒到几十秒，正常现象）。
3. 按 **F5** 运行主场景，确认能进主菜单、背景图正常显示（背景图就是那 4 个 LFS 大图之一）。

### 命令行无界面验证（双闸门，供 CI/AI 窗口用）
```bash
GODOT="D:/wuxia-game/Godot_v4.7.2-stable_win64_console.exe"
# GATE1：零 SCRIPT/PARSE/COMPILE ERROR
"$GODOT" --headless --path "D:/wuxia-game" --quit 2>&1 | grep -E "SCRIPT ERROR|Parse Error|Compile Error"   # 无输出=过
# GATE2：✗=0 且 套件失败=0
"$GODOT" --headless --path "D:/wuxia-game" "res://tests/unit/run_all.tscn" 2>&1 | grep -c "✗"   # 必须为 0
```
> ⚠️ 路径必须 **Windows 风格**（`D:/wuxia-game`），不要用 `/d/wuxia-game`，否则 Godot 静默不跑、误报绿。

## 5. 不会进版本库的东西（别慌）

`.gitignore` 已排除所有 `_backup_hires/`、`_jpg_backup/` 高清备份图（约 50MB）。这些**不会**被克隆下来，也**不需要**——它们是本地压缩工具的源图备份，游戏运行不依赖它们。

克隆下来的体积 ≈ 工作树 511MB + `.git` 227MB + LFS 15MB ≈ 753MB，远在 GitHub 免费额度内。

## 6. 开发纪律（多 AI 并行项目，必读）

这是**多 AI 窗口并行开发**的仓库，提交有铁律：

1. **提交权收口**：各窗口（含你）改完只入队，不自行 commit/push。入队命令：
   ```bash
   # 注意用本机管理的 Python（见 MEMORY.md 路径），不是系统 python
   python tools/commit_queue.py add --window <你的窗口名> --message "..." --files a.gd b.json
   ```
2. 提交前必须过**双闸门**（GATE1+GATE2，见第 4 节）。
3. 改动前/后登记 `tools/change_log.py add`；调试先查变更日志与隐患传递板。
4. 文件主权：开工前声明本次改动文件清单，绝不碰 `preset_10x10.json` / `preset_12x12.json` 等战斗预设（属战斗窗口主权）。
5. 完整规则见 `docs/变更通告_协同总纲_全员必须遵守.md`（骨血总纲）与 `docs/PM_flush_提示词.md`（收口流程）。

## 7. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 克隆后游戏背景图是空白/报错 | LFS 大图没拉下来 | `git lfs pull` |
| `ssh -T git@github.com` 报 Permission denied | 公钥没加到 GitHub / 不是协作者 | 检查第 2 步 |
| Godot 打不开工程、报版本错误 | Godot 版本不是 4.7.2 | 装 4.7.2（见 1.2） |
| 首次打开卡很久 / 报错 class 未声明 | `.godot` 缓存没建好 | 关掉 Godot 重开一次，或删 `.godot` 让其重建 |
| `git clone` 走 HTTPS 要账号密码 | 应用了 HTTPS 地址 | 用 SSH 地址 `git@github.com:asiuuua/wuxia-game.git` |
