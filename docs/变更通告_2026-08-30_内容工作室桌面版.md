# 变更通告 · 内容工作室「桌面版」（2026-08-30 续）

## 一、背景
用户（零代码小白）希望把之前做的「内容工作室」编辑器插件做成**独立桌面工具**，并加强两件事：
1. NPC 位置"对不上地图"的困扰 → 加可视化定位。
2. 唯一 ID / 引用 ID 误改风险 → 加防误改保险 + 一键回滚 + 日志。

## 二、交付物
`tools/desktop_studio/` 下：
- `studio_core.py` —— 核心逻辑（读写 + 保险/日志/回收站/重命名）。
- `studio_server.py` —— 本地 Web 服务（纯标准库，零依赖）。
- `index.html` —— 浏览器界面（原生 JS，无 CDN，可离线）。
- `studio_launcher.bat` —— 双击启动（自动开浏览器）。
- `README.md` —— 使用说明。
- `dist/工作室专业调教.exe` —— PyInstaller 打包的**真·exe**（双击即用，不依赖 Python）。
- `safety_data/` —— 自动生成（回收站/备份/日志/设置），已 gitignore。

> 与 Godot 里的「内容工作室」插件**读写同一批数据文件**，二选一即可；桌面版额外多了地图预览与 ID 保险。

## 三、关键设计澄清（已与用户确认）
- **NPC 非随机摆放**：游戏 `TownScene.gd:200` 按 `town_npcs.json` 的 `pos_x/pos_y` 精确生成，工具只负责填数据，实例化由游戏完成，**无需写代码**。
- **位置"对不上"= 坐标填错**：新增「🗺 地图坐标预览」画布，点一下地图即设 `pos_x/pos_y`；另有"参考现有 NPC 坐标"一键抄坐标。

## 四、新增功能
1. **地图坐标预览画布**：左侧选/新建 NPC → 画布点选落点 → 自动写回坐标，所见即所得。
2. **唯一 ID 四重保险**：
   - 默认锁定，手滑改不到；
   - 改 ID 需两次确认弹窗，且走"删旧建新"逻辑（不重复）；
   - 「↩ 回退原ID / ↩ 撤销重命名」一键还原；
   - 旧记录进回收站可恢复。
3. **引用 ID 防误改**：对话/任务/战斗 ID 改动弹确认框（取消即还原）；保存时校验"对话 id 是否存在于剧情表"，不存在则提醒。
4. **真·exe 打包**：`PyInstaller --onefile --windowed` 生成 `dist/Studio.exe`。

## 五、验证
- 核心逻辑自检（studio_core self_test）：增/删/改/回收站/恢复/日志 全过。
- 本地服务冒烟：settings/NPC/对话/欢庆/回收站/首页 全部 HTTP 200。
- 双闸门：GATE1 CLEAN；GATE2 套件 通过 43 · 失败 0。
- 工程文件未被改动（冒烟测试产生的本地安全数据已清理，`town_npcs.json` 已还原）。

## 六、使用须知
- 工具是**本地程序**，需先启动（双击 `.bat` 或 `Studio.exe`）才打得开网页；不是常驻网站。
- 端口 8765，**同时只能跑一个实例**（重复启动会提示地址被占用，关掉前一个即可）。
- 编辑时勿同时用 Godot 跑游戏改同一文件。
- 改完按 F5 跑游戏查看效果。
