## 一、本窗口做了什么
在 M1（好感度/送礼/好感度事件）+ M2（姻缘内核：无限配偶/求婚/结婚/子嗣预留）之上，新增**关系网数据中枢 `RelationshipService`**：
把 `BondService`（好感度）与 `RomanceService`（配偶/子嗣/孕期）的数据聚合成**一张统一关系图**，作为"关系网视图"与"右上角姻缘按钮"的**唯一数据来源**。

- 自身**不持有任何状态**、**不进存档**、**不碰 `screens.json`**（屏名注册归 UI 模块主权，见第五节）。
- 纯聚合门面：`get_relationship_graph()` 一次返回 nodes（每个 NPC 的好感/配偶/子嗣/孕期/可结缘）+ spouses + children + summary。
- 扩展点：结义(sworn)/师徒(master) 服务建成后，只需在 `_node_of()` 补两个状态来源（与 `is_spouse/children` 同构），图即自动包含，UI 零改。
