# 变更通告 · 新增区域「填表模式」（2026-08-30）

> 需求：用户（零代码小白）后期要往框架里加大世界场景/战斗场景，希望「新增区域」能像填表一样、零代码完成。此前 `MapScreen`（按 M 的世界地图面板）把 9 个区域名**硬编码**在 `REGION_KEYS` 常量里；且玩家没有任何「在区域间传送」的手段。本批把区域改成**数据驱动注册表**，并让地图面板可点击直接传送。

## 一、改动文件清单

### 数据（新增）
- `data/configs/world/regions.json`（**新增**）：区域注册表。`_doc` 字段写明「新增区域只做两步：① 做场景 .tscn；② 表加一行」，对小白友好。`region_start_town` 指向真实 `TownScene.tscn`，其余 8 个 `scene_path` 留空（占位，用户做好场景后填一行即可）。每个区域含 `name`(直接显示，免改 strings.csv) / `scene_path` / `type` / `connections`(可达区域 id 图)。

### 共享地基（冻结区 · 只增不改）
| 文件 | 变更性质 | 说明 |
|------|----------|------|
| `autoload/ConfigManager.gd` | 只增不改 | 新增 `_regions` 缓存 + `_ensure_regions()` + `get_region(id)` / `get_all_region_ids()` / `get_region_connections(id)`，按 `get_map_layout` 同款 `_load_json` 模式加载 `regions.json`；加载时剔除 `_` 开头的元数据键（如 `_doc`）。 |

### 业务层
- `autoload/GameManager.gd`：新增 `current_region_id`（默认 `region_start_town`）；`new_game` / `load_game` / `return_to_safe_point` 进入城镇时复位为 `region_start_town`；新增 `goto_region(id)`（查表取 `scene_path` → `reclaim_all` + `change_scene_to_file`；`scene_path` 为空弹 Toast「区域尚未实装」、id 不存在弹「未知区域」，均不卡死）。
- `scenes/ui/overlays/map/MapScreen.gd`：删除硬编码 `REGION_KEYS` / `CURRENT_REGION_KEY`，改为读 `ConfigManager`；当前区域名由 `GameManager.current_region_id` 取；`_fill_grid` 用 `Button` 列出全部区域（高亮当前），点击 → `GameManager.goto_region(id)`。

## 二、核心设计

### 填表模式怎么用（给用户的零代码流程）
1. 在 `resources/` 下做好新区域场景，如 `res://scenes/gameplay/world/MyPlace.tscn`（你用编辑器搭好地图/装饰即可）。
2. 打开 `data/configs/world/regions.json`，加一行：
   ```json
   "region_my_place": { "name": "我的地盘", "scene_path": "res://scenes/gameplay/world/MyPlace.tscn", "type": "world", "connections": ["region_start_town"] }
   ```
3. 游戏里按 **M** 打开世界地图 → 点「我的地盘」→ 直接传送过去。**全程不碰任何代码。**

### 防呆
- `scene_path` 留空 = 该区域已登记但场景未做，点击只提示不崩溃（避免小白先登记后忘做场景导致黑屏）。
- `connections` 仅用于「地图总览」展示；传送不受连接限制（世界地图可直达任意已登记区域）。
