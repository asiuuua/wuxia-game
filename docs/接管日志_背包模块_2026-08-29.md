## 6. 已知坑（本轮已踩过，勿再踩）

- **沙箱快照**：Bash 工具沙箱内 Godot 读到的是 git-HEAD 快照，untracked 新文件不可见 → 验证前必须 commit。
- **退出码不传播**：GATE2 靠 `套件：... 失败 N` 的 N 判成败，勿信 `$?`。
- **typed Array 禁 `as Array[String]`**（崩）→ 循环 append；`mini/maxi` 仅 2 参 → 多参嵌套。
- **EventBus 双源**：共享地基信号已在 master，改前先 grep 确认是否已有，避免重复声明级联 Parse Error。
- **`add_child busy` / 存档解析 ERROR** 是测试环境固有噪声，不计入套件失败，无需为它们改代码（除非某套件真失败）。
