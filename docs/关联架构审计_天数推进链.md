## 二、隐藏风险 / 残点（链上唯一未闭环处）

**残点 R1：休息入口被 UI 遮挡静默吞输入**
- 证据：`TownScene.gd:331` `if UIManager.is_any_screen_open(): return` —— `_do_rest` 在任一界面打开时**静默 return，无任何提示**。
- 影响：玩家在**结缘/背包/关系界面内按 R 期望推进天数（催熟孕期）时，什么都不会发生、也不报错**。休息推进天数的唯一玩家入口是「城镇 R 键」。
- 根因归类：与全量报告 BUG-10/11（UI 屏栈遮挡导致输入静默吞）**同一根因家族**。属「表面无错但行为异常」的隐性 BUG，非阻断性崩溃。
- 设计判断：休息本就是城镇活动，镇内不开放休息或属合理；但若设计意图是「结缘界面也能靠休息催孕期」，则此处是缺口。需产品拍板。

**残点 R2（进程级，非代码）：待办清单状态失真**
- 记忆缓存曾将这两条项标为 🔴 blocked；实查 `docs/backlog.json:262-294` 已 `status:"done"`（resolvedBy=结缘窗口，commit 948d146，resolution 已闭环）。
- 这是审计八维度中「未完成执行清单失真」的典型：清单真值正确，但跨窗口记忆同步滞后。已在本窗口纠正（见 §三）。
