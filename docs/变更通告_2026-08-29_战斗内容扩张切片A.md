## 一、目标

约束：
- 纯数据 + 测试，不增任何战斗逻辑（逻辑内核已由 M3-1/M3-2 交付并单测覆盖）。
- 不碰共享地基（EventBus / enums / ConfigManager / screens.json / strings.csv / ui_anim.json）。
