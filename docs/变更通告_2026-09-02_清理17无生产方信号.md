## 变更原因
关联架构审计（FINDING-2）：EventBus 契约表有 17 个无生产方信号，属契约噪音——新 AI 按 `test_eventbus` SEAMS 误以为这些信号在用，可能写出接空信号的代码。CMD 7 个经确认已由 `GameManager.xxx_service` 直调替代；事件 9 个为预留空壳。本次按审计建议统一清理，降低契约噪音、让门禁基线保持精确。

## 影响面
- 被删信号在当前工程**全树零 emit、零 connect**（仅 `docs/模块卡` 曾标注「归 X 窗口主权 / 空壳待接线」，属旧状态描述）；删除后**不崩任何现有代码**。
- `player_exp_changed` **保留**：`scenes/ui/overlays/hud/status_card_panel.gd:50` 有 connect（HUD 订阅），但生产端 `data/runtime/player_state.gd` 的 `gain_exp()` 从不 emit。归 UI 窗口处置——要么 `gain_exp` 补 `emit` 且 HUD 显示经验条，要么删信号 + HUD connect。
- 共享地基改动，需各窗口知晓：若战斗 / 锻造 / 商店 / 门派 / 姻缘 / 配置 / 任务 / UI 窗口未来要用到被删信号，须重新在 `EventBus.gd` 声明（走派单 / 协同）。
