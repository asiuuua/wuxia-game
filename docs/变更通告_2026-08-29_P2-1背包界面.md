## 一、共享地基增量改动

- `data/configs/localization/strings.csv`：**UI 窗口主权内**的本地化增补，仅**新增** 5 个 key（`ui_inventory_tidy` / `ui_item_use` / `ui_item_equip` / `ui_item_discard` / `ui_item_split`，含 zh_CN/zh_TW/en 三语），不覆盖、不冲突既有 key；原有背包 key（`ui_inventory_title`/`_weight`/`_main`/`_material`/`_quest`/`_close`）未动。
- `EventBus` 信号**未变更**：仍 `inventory_item_added(item_id, count)` / `inventory_item_removed(item_id, count)`（均为 2 参）。UI 窗口的 `_on_inv_changed` 已对齐为 2 参签名，消除此前「Method expected 1 argument(s), but called with 2」的运行时错误。
- `core/enums/*_enums.gd` / `ConfigManager.gd` / `screens.json` / `UIManager.gd` **本轮未改动**。
- ⚠️ **接口变更触发**：背包窗口的 `services/inventory/inventory_service.gd` 本轮新增 3 个公开方法，该文件已纳入 `tools/gen_contract.gd` 的 `CONTRACT_FILES`。按 SOP「接口改动须重跑 gen_contract」，**此重跑由背包窗口执行**（`gen_contract.gd` 与 `inventory_service.gd` 均属背包窗口主权，UI 窗口不代跑），见第二节 B。

## 二、本轮改动清单（按主权归属分组）

### A. UI 窗口主权内（其他窗口请勿改这些文件）
- `scenes/ui/components/item_slot/ItemSlot.gd`：**新增** 64×64 物品槽组件。
  - 信号：`slot_pressed(iid)` / `slot_context(iid)` / `slot_hover(iid)` / `slot_drop(iid, data)`。
  - `setup(inst)`：`inst` 为 `ItemInstance`，传 `null` 表示空槽；展示名称 + 稀有度色（`_rarity_color`）+ 数量角标（`xN`）+ 锁图标（`inst.locked`）；底色走 `UIPalette.GLASS_BG`，选中态 `GLASS_BORDER_FOCUS`。
  - 拖拽：`_get_drag_data` 返回 `{ "iid": _iid }`；`_can_drop_data`/`_drop_data` 校验并转发 `slot_drop`。
  - **幂等保护**：`_build()` 首行 `if _label != null: return`，`setup()` 在 `_label == null` 时先 `_build()`。允许调用方在 `add_child` 之前调用 `setup()`（修复冒烟中「`setup` 先于 `_ready` 导致 `_label` 为 `Nil`、`.text` 赋值 SCRIPT ERROR」的 bug）。
- `scenes/ui/components/tooltip/Tooltip.gd`：**新增** 鼠标忽略（`MOUSE_FILTER_IGNORE`）悬停浮窗。
  - `show_for(item_id, global_pos)`：类型 + 稀有度 + 描述，`UIPalette.GLASS_BG` 面板 + `GOLD` 标题，`await process_frame` 后按视口钳制（`mini/maxi` 双参）避免出界。
  - `hide_tip()`：隐藏。
- `scenes/ui/overlays/inventory/InventoryScreen.gd`：**整体重写**为三栏实例网格交互界面（非只读聚合）。结构：
  - `_build()`：压暗遮罩 `ColorRect`（`UIPalette.DIM`，`MOUSE_FILTER_STOP`）+ 居中磨砂玻璃 `Panel`（720×560，`UIPalette.GLASS_BG` StyleBoxFlat 圆角 14 / 细白边 / 阴影 18 + 偏移）+ header（金色标题 / 负重 Label / 整理按钮 `ui_inventory_tidy` / 关闭按钮）+ 三栏 `ScrollContainer` + `GridContainer(columns=8)`，各栏 `GridContainer` 存入 `_grids` dict；末尾挂 `_tooltip`。
  - `_fill_grid(bag_name, inv)`：按 `ItemInstance` 逐个实例化 `ItemSlot`（非聚合），末尾补一个空槽（传 `null`）。
  - `_on_slot_pressed(iid)`：消耗品（`type==pill` 或 `CONSUMABLE` 位）→ `inv.use_item` 并 `_refresh()`；否则开右键菜单。
  - `_open_context(iid)`：按 `ItemFlag`/`equip_slot`/`KEY_ITEM` 构建 `PopupMenu`（使用 0 / 装备 1 / 丢弃 2 / 拆分 3），`id_pressed`→`_on_context_id`。
  - `_on_context_id(id)`：0→`use_item`；1→`GameManager.equipment_service.equip`；2→`remove_instance`；3→`split_instance(count/2)`；均 `_refresh()`。
  - `_on_slot_hover(iid)`→`_tooltip.show_for`；`_on_slot_drop(target_iid, data)`→`inv.move_instance(src_iid, tgt_bag, _index_in_bag(...))`。
  - `_on_sort()`：三栏 `inv.sort_bag(...)` 后 `_refresh()`。
  - `_on_inv_changed(_a, _b)`：接 2 参 `EventBus` 信号，触发 `_refresh()`；`_exit_tree` 断开连接防泄漏。
  - `_unhandled_input`：ESC→`UIManager.close_screen(self)`。
  - 配色/字号全走 `UIPalette`，无裸色值。
- `data/configs/localization/strings.csv`：+5 key（见第一节）。
- `tests/ui/inventory_smoke.gd` + `tests/ui/inventory_smoke.tscn`：**新增** 背包界面冒烟。reset→加 5 丹 +1 剑→构建界面→断言 ≥2 `ItemSlot`；`use_item` -1；`split_instance` 前后总数量不变；`move_instance` 跨栏至 material；`sort_bag`；`equip`；`remove_instance`；输出 `[INV] ALL_INV_OK pass=12 fail=0`。

### B. 背包窗口主权内（需背包窗口知会 / 执行）
- `services/inventory/inventory_service.gd`：P2-1 为 UI 窗口新增 3 个公开方法（UI 强依赖，勿改名/改参）：
  - `split_instance(iid: String, count: int) -> Dictionary`：校验可堆叠、`0 < count < inst.count`、存在空槽；创建新 `ItemInstance`，**总数量守恒**（仅分布变化）。返回 `{ "ok": bool, ... }`。
  - `move_instance(iid: String, target_bag: String, target_index: int) -> bool`：跨栏/同栏移动，目标槽位已占用则交换；返回是否成功。
  - `sort_bag(bag_name: String) -> void`：按 名称 → 类型 → 稀有度 排序，非空实例优先。
  - 另含私有辅助 `_bag_by_name(name)`（不对外）。
  - **并发编辑修复**：本轮在追加方法时，发现并修复了 `remove_instance` / `consume_instance` 因并发编辑导致的**缩进损坏**（前者循环体未缩进、后者多缩进一级），该损坏曾致整文件 `Parse Error`（"Could not parse global class InventoryService"）。修复后经 `--quit` 闸门复绿。
  - **接口变更触发**：本文件已在 `gen_contract.gd` 的 `CONTRACT_FILES` 内，新增 3 公开方法后，**须由背包窗口重跑 `tools/gen_contract.gd`** 刷新 `docs/契约总表.md`（gen_contract 同为背包窗口主权，UI 窗口不代跑）。
