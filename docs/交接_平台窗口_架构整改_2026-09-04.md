## 三、我的核心结论（修正后的）

> **修正声明**：我第一轮分析**偏乐观**（只抽查了部分文件）。对照外部评估逐条实测后，判断修正为：
> **当前是"可玩的多个系统原型"，不是"可持续生产大型 CRPG 内容的平台"。**

### 3.1 最关键的判断

**不推倒重来，做「底层接缝重构 + 渐进迁移」。**
**最急的不是统一代码风格，而是止血** —— 数据正在漂移，且**已写好的区域剧情运行时根本解释不了**。

### 3.2 实测确认的 13 项问题（证据在本文件与路线文档的表格里，均带 file:line）

最严重的三条：

1. **已写好的区域剧情跑不起来**（最高）
   `regions/newbie_village/dialogs/nv_dialog_elder.json` 用 `speaker`/`effects:["set_flag:xxx"]`，
   而 `dialogue_service` 要 `speaker_id`/`next_id`/`options`/`cond`/`trigger_events`；
   执行器只认 `sfx`/`shake`/`quest_accept`/`quest_complete`，**不认 `set_flag:`**。
   → 内容写了但运行时解释不了，且此前无人发现。

2. **两套区域系统并存**
   `ConfigManager.gd` 95-96 行读 `regions/_map_index.json`（内容区），579-589 行读 `world/regions.json`（传送区）。ID 体系不同，无权威映射。

3. **好感三重真源**
   `flag_store.gd:8` 写 `global_flags["favor:<id>"]`、`bond_service.gd:14` 存 `affections`、`game_state.gd:14` 存 `affinity`。

其余：GameManager 持 15 服务（Service Locator）、条件三套方言、命令未成形、任务目标类型写死、奖励硬编码分发、无 Tag、无 AI 领域、无存档迁移器、**无一键验证脚本**。

### 3.3 优先级重排（重要，别照外部文档的 P0–P6 直接做）

**我把「停双写」提到最前，把「统一 Condition/Command」从原 P0 下调到 P3。**
理由：**数据漂移比代码重复更致命** —— 条件重复只是"以后加功能麻烦"，双写 + 剧情跑不了是"现在就在坏"。

```
P0 止血：停 town_npcs 双写 + 干净基线 + 一键验证 + 构建阻断   ← 最急
P1 统一区域真源（两套并一套）
P2 让已写好的区域剧情真正跑起来
P3 统一 Condition / Command（原 P0，已下调）
P4 状态所有权与存档
P5 工具边界（校验器 + 引用索引，不做编译流水线）
```

### 3.4 一个重要的风险修正

外部评估说「158 项未提交变更，不要当成稳定基线」。**实测后我认为它高估了风险**：

| 目录 | 数量 | 性质 |

| resources | **113** | 纹理压缩 `.import`/`.bak` **机械改动，非架构问题** |
| docs | 17 | 文档 |
| data | 13 | 配置（需 triage） |
| tools | 6 | 工具 |

→ **真正需要 triage 的只有约 45 项**，113 项是机械改动（M=129 / ??=25 / D=4）。

## 四、领域划分对照的结论（用户第 12 问的答复）

**系统确实按领域划分，不是按表堆的 —— 这道分水岭我们已过。**
`services/`（12 领域）与 `data/configs/` 均为领域结构。

**但有一条规定，其他窗口务必遵守、不要去改：**

> **顶层保持 `autoload → core → data → services → scenes → resources`（层优先），
> 不改成外部文档主张的「域优先顶层」。**
> 理由：① 单向依赖铁律靠此分层强制；② Godot 工程惯例；③ 单人 2D 项目改成域优先是纯 churn 零收益。

**Core 原语覆盖 5/10**：有 Event / Time / Random / Save / Localization；
**缺 ID / Command / Condition / Tag / Reference** → 补齐这 5 个就是 P3。

领域状态：Combat ✅最完整、Relationship ✅超预期、Item/Faction(sect)/Economy(shop)/Tools ✅；
Quest ⚠️、Narrative ⚠️、World ⚠️、**AI ❌ 完全缺失**。
