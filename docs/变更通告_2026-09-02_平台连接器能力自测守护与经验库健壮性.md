# 变更通告 2026-09-02 · 平台连接器能力自测守护与经验库健壮性

> 模块：工作室平台(tools/desktop_studio)　改动范围：tools/desktop_studio/security_selftest.py、studio_server.py　commit：待提交后补
> 责任窗口：AI-战斗　关联：docs/更改日志.md 对应行

## 变更项
- security_selftest.py：新增 _test_connector_and_knowledge() + _read_free() 共 8 项回归，守护「跨项目知识复用 + 换皮模板（连接器而非容器）」能力：
  - 工程清单可枚举（list_projects 至少 1 个工程）
  - manifest 可读、ai_context / reskin 换皮清单 / knowledge 经验清单三段均真正读出
  - knowledge.refs 富化可用（_exp_enrich 产出 refs + facets）
  - 经验库文档读取路径穿越防护（越界目录被拒、md 之外被拒）
- studio_server.py：_exp_enrich() 循环内预置 grade = ""，消除当某条 knowledge.refs 文档读取失败/非文档时 grade.split() 抛 UnboundLocalError 的潜在崩溃。

## 变更原因
- manifest 三段（ai_context / reskin / knowledge）此前已由 loader/server 读取并渲染（经验库面板 tab-exp 早已落地），但整套平台能力没有任何回归测试守护，属待固化易回退风险。
- 补自测时实测撞出 _exp_enrich 的健壮性缺陷：当 refs 里含 glob 展开、且某文档读取失败（try/except 吞错后 grade 未定义）即崩。线上靠「文档恰好都在」而未触发，属隐性隐患。

## 影响面
- 涉及 tools/desktop_studio/studio_server.py（共享平台基建里的知识富化函数）；security_selftest.py 新增测试。未动 EventBus/ConfigManager/core/enums/GameManager/GameState 等游戏侧共享地基。
- 不影响任何游戏逻辑/数据；仅平台管理工具的健壮性 + 自测覆盖加严。
