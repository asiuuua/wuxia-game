## 三、整体架构框架（分层 + 数据流）

```
┌──────────────────────────────────────────────────────────┐
│                       scenes/ 表现层                       │
│  Bootstrap → MainMenu → TownScene ⇄ BattleScene          │
│  UI: 主菜单/背包/装备/炼药/难度/ESC/属性/地图/存读/对话     │
└───────────────┬──────────────────────────────────────────┘
                │ 只调用，不持业务数据
┌───────────────▼──────────────────────────────────────────┐
│                  GameManager (装配中枢)                    │
│  持有: player_state / inventory / ability / equipment /    │
│        combat / quest / alchemy / forge / shop / sect      │
│  负责: start_new_game / start_battle / return_to_safe_point│
└───────────────┬──────────────────────────────────────────┘
                │ 业务层(RefCounted, 不持 Node)
┌───────────────▼──────────────────────────────────────────┐
│                  services/ 业务层                          │
│  combat / inventory / ability / equipment / quest /        │
│  alchemy / forge / shop / sect                            │
│  跨模块只走 EventBus；数值全在 data/configs JSON          │
└───────────────┬──────────────────────────────────────────┘
                │
┌───────────────▼──────────────────────────────────────────┐
│   core/(枚举/接口/常量)  ·  data/configs/(JSON 数值)       │
│   data/runtime/(Resource 状态)  ·  autoload/(全局管家)     │
└──────────────────────────────────────────────────────────┘
```

**铁律（四底线，不可妥协）**：分层单向依赖 / 事件驱动（EventBus）/ 数据驱动（JSON）/ 命名见名知意。

**剧情数据流（零基础最关心的一段，已全部接好）**：
```
NPC(json) ──对话──▶ DialogOverlay ──接任务──▶ QuestService
   │                                              │
   └──战斗id──▶ GameManager.start_battle ──▶ BattleScene
                                                  │ 胜利
                                                  ▼
                                          QuestService 推进目标
                                                  │ 完成
                                                  ▼
                                          发奖: 经验/银两/物品/武学 → 背包/玩家
敌人(json) ◀──战斗配置(battles.json) 的 enemy_ids 拉取，掉落 loot → 物品(json)
```

## 五、零基础剧情导入 · 最简方案（重点）

**你不会写代码也没关系。** 我已做好一套 `tools/story_import/` 工具包：

```
tools/story_import/
├── 人物模板.csv   ← 填：谁、在哪、说什么、给什么任务
├── 任务模板.csv   ← 填：任务名、打哪场战斗、给啥奖励
├── 战斗模板.csv   ← 填：战斗名、放哪几个敌人
├── 敌人模板.csv   ← 填：敌人属性、掉什么
├── 物品模板.csv   ← 填：自定义道具（任务奖励/掉落）
├── convert.py     ← 转换器（你不用看）
├── run.bat        ← 双击它就行
└── README.md      ← 零基础图文步骤
```

**操作流程（3 步）**：
1. 用 Excel 打开 5 个 csv，删掉里面 `demo_` 示例行，填你自己的内容。
2. **上下表的 id 对上**（人物.任务id = 任务.任务id；人物.战斗id = 战斗.战斗id；任务.目标战斗id = 战斗.战斗id；战斗.敌人id = 敌人.敌人id；奖励/掉落物品id = 物品.物品id）。
3. **双击 `run.bat`** → 看到"导入完成" → 用 Godot 进城镇，走过去和 NPC 对话，任务/战斗就触发了。

**安全**：按 id 合并，已存在自动跳过，不覆盖不重复；只动 `data/configs/` 的 JSON，永远不碰代码。已用 `demo_` 示例端到端验证通过（游戏加载零错误）。

详细字段说明见 `tools/story_import/README.md`。
