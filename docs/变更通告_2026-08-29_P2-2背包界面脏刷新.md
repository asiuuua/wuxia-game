# 变更通告 · P2-2 背包界面脏刷新

- **日期**：2026-08-29
- **窗口**：UI 窗口（主权：`scenes/ui/**`）
- **类型**：内部性能/体验优化（无接口/无行为变更）

## 一、改动内容
- 文件：`scenes/ui/overlays/inventory/InventoryScreen.gd`
- `_fill_grid()` 由「每次 `queue_free` 全量重建 + 重新 `new ItemSlot()` + 重连信号」改为**节点复用脏刷新**：
  - 维护 `_slot_by_iid: Dictionary`（`iid → ItemSlot`）。
  - 按目标序列（非空实例 + 末尾一个空槽）逐位置复用 `GridContainer` 既有子节点；仅当**槽位内容签名**变化时才调用 `slot.setup()`。
  - 内容签名 `_slot_sig(inst) = "iid#count#locked"`，任一变化（数量增减、锁定、iid 迁移）才触发重绘；空槽签名为 `"EMPTY"`。
  - 超出目标长度的尾部槽位 `remove_child` + `queue_free`，并同步清理 `_slot_by_iid`。
- 新增私有辅助 `_slot_sig(inst)`。

## 二、为什么算"脏刷新"
原实现每次刷新（含 `use_item`/`split`/`move`/`sort`/EventBus 通知）都销毁重建全部槽节点；
本改动只重建"真正变了"的槽，**保留未变槽的 Control 节点与已连信号**，消除重建抖动、降低 GC 压力。

## 三、行为一致性（回归保护）
- 渲染结果与原实现逐像素一致：非空实例按栏顺序铺格 + 末尾单个空槽（有物品时）；空栏不显示空槽。
- 数量变化（用药 -1、拾取 +N、拆分分布）、锁定图标、拖拽移动、排序重排、装备/丢弃后刷新均通过 `inventory_smoke` 12 项断言。
