# M3 设计 · 演出动效令牌化（M3-3，战斗窗口主权）

> 上游：M1 战斗逻辑内核 / M2 演出编排 / M3-1 敌人 AI 选技能 / M3-2 状态引擎扩护盾·反弹·复活

> 治理：git 提交统一由 UI 模块执行；本窗口只产代码 + 变更通告 + 对话内精确文件清单，不自 `git commit`。

## 一、目标
把 M3-2 在逻辑层落地的三个机制（护盾 / 反弹 / 复活）**可视化**，并完成战斗演出层的**动效令牌化**（M2 起 `ui_anim.json` 的 `battle` 令牌块一直缺失，Director 靠 `_FALLBACK` 兜底）。

约束：
- 本 M3-3 **纯演出层**，不增任何战斗逻辑（逻辑 + 事件契约已由 M3-2 交付并单测覆盖 23/23 绿）。
- 演出层对未知事件 `match` 静默跳过（M2 已验证安全），本 M3-3 显式消费 `SHIELD_ABSORB / REFLECT / REVIVE`。
- `ui_anim.json` 的 `battle` 令牌块属 **UI 窗口主权**（共享地基），战斗窗口**不编辑**它，只在本通告给出完整规格，交由 UI 模块纯增。在 UI 模块补块前，Director 用 `_FALLBACK`（本 M3-3 一并补上三机制意图时长）保证手感正确。

## 二、事件契约回顾（来自 M3-2，本窗口只读消费）
| 事件 | actor_id | target_id | value | target_hp_after | target_shield_after |
|---|---|---|---|---|---|
| `SHIELD_ABSORB` | 攻击者 | 承受者 | 本次吸收量 | 承受者新血(不变) | **剩余护盾** |
| `REFLECT` | 反弹者 | 攻击者(承伤) | 反弹伤害量 | 攻击者新血 | — |
| `REVIVE` | 复活者 | 复活者 | 复活后血量 | 复活者新血 | — |

⚠️ **关键**：`REFLECT` **不**发独立 `DAMAGE` 事件（反弹伤害在 `_resolve_hit` 内直写攻击者），演出必须据此 `target_hp_after` 更新攻击者血条；否则攻击者血条不降。

## 三、方案（战斗窗口主权文件）

### 1. `scenes/gameplay/battle/unit_hud.gd`
- `_ready`：在血条(y=22)上方加一条青色细盾条 `_shield_fill`（y=18，高 4px，色 `Color(0.4,0.95,0.95)`），初始宽 0。
- `set_shield(shield: int)`：按 `shield / max(1,_max_hp)` 比例 tween 盾条宽度（复用 `_tween_bar`，服从 `_instant`）。
- `play_revive()`：叠一层金色闪光 `ColorRect`（覆盖 HUD，`alpha 0.55`），tween `modulate:a→0` 0.35s 后 `queue_free`；`_instant` 时直接跳过。

### 2. `scenes/gameplay/battle/battle_view.gd`
`play_event` 的 `match` 增三分支：
- `SHIELD_ABSORB` → `_play_shield`：`hud.set_shield(ev.target_shield_after)` + 青色飘字 `盾%d`（吸收量）。
- `REFLECT` → `_play_reflect`：`hud.set_hp(ev.target_hp_after)`（更新攻击者血条）+ 紫色飘字 `反弹%d`。
- `REVIVE` → `_play_revive`：`hud.set_hp(ev.target_hp_after)` + `hud.play_revive()` + 金色飘字 `复活!`。
- **顺带修 `-0` 飘字**：`_play_damage` 加 `elif ev.value > 0` 守卫——护盾全吸收时 `DAMAGE.value==0`，不再飘难看的 `-0`（部分吸收仍飘剩余伤害）。

### 3. `scenes/gameplay/battle/battle_director.gd`
- `_token_for` 增：`SHIELD_ABSORB→"shield_absorb"` / `REFLECT→"reflect"` / `REVIVE→"revive"`。
- `_FALLBACK` 补齐意图时长（战斗窗口主权，使令牌在 `ui_anim` 缺 `battle` 块前也有正确手感）：
  `damage_pop:0.12 / hit_shake:0.12 / turn_gap:0.1 / death_fade:0.4 / shield_absorb:0.12 / reflect:0.14 / revive:0.35`（原有的 `instant/fast/normal/gentle/slow` 保留）。
