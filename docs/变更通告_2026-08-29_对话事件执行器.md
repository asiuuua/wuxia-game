# 变更通告 · 对话事件执行器（2026-08-29）

## 目标
把对话行 `trigger_events` 从「只 emit 信号、无人订阅」升级为**真正演出**：
- 音效（sfx）
- 震屏（shake）
- 接任务 / 交任务（quest_accept / quest_complete）

数据驱动：事件键 → 效果列表，全部配置在 `data/configs/dialogs/dialogue_events.json`，换效果只改表不动代码。

## 共享地基增量（ConfigManager，纯追加，只增不改）
| 新增 | 说明 |
|---|---|
| `const DIALOG_EVENT_FILES` | 事件映射表路径 |
| `var _dialog_events: Dictionary` | 事件键 → 效果数组 |
| `_load_dialog_events()` | `_ready` 中调用，加载并校验（非数组/重复键容错） |
| `get_dialogue_event(key: String) -> Array` | 取效果数组，未配置返回 `[]` |

## 新增文件
| 文件 | 说明 |
|---|---|
| `services/dialogue/dialogue_event_executor.gd` | `class_name DialogueEventExecutor`（RefCounted）。`setup()` 订阅 `EventBus.dialogue_event_triggered`；`_on_event` 查表→`_apply_effect` 按 type 分发；单条出错不影响其余、整体不崩 |
| `data/configs/dialogs/dialogue_events.json` | 事件键 → 效果数组。映射现有 `sfx_*` 5 个键；新增示例 `bandit_threat_shake`（震屏）、`accept_demo_quest`（接 `demo_quest`） |
| `tests/unit/test_dialogue_event_executor.gd` | 3 项单测：未知键不崩 / 缺失音效静默 / 接任务使 `demo_quest` 激活 |

## 装配（GameManager，纯追加）
- 新增 `var dialogue_event_executor: DialogueEventExecutor`
- `_init_services()` 中 `dialogue_event_executor = DialogueEventExecutor.new()`
- `_ready()` 中 `dialogue_event_executor.setup()`（与 `cmd_start_combat` 同批接线）

## 效果类型与降级
| type | 行为 | 降级 |
|---|---|---|
| `sfx` | `AudioManager.play_sfx(path)` | 路径空 / 文件缺失 → 静默跳过（避免占位期日志噪声） |
| `shake` | 拿当前场景相机 Tween 随机偏移 | 无相机 / 服务缺失 → 跳过；相机实例失效有 `is_instance_valid` 守卫 |
| `quest_accept` | `quest_service.accept(quest_id)` | 服务缺失 / 空 id → 跳过 |
| `quest_complete` | `quest_service.complete_quest`（存在时） | 同上 |

## 接线闭环
对话行 `trigger_events:[...]` → `DialogueService._present_current` emit `EventBus.dialogue_event_triggered` → `DialogueEventExecutor._on_event` 查 `dialogue_events.json` → 演出。

## 验证
- 双闸门全绿：`--quit` 零 SCRIPT/PARSE/COMPILE ERROR；`run_all` 25→26 套件 0 失败 0 ✗（新增 1 套件）。
- 新增 `class_name DialogueEventExecutor` 已 `--editor --quit` 重建 `.godot` 类缓存。
- 契约总表：`get_dialogue_event` 已登记（信号 `dialogue_event_triggered` 此前已存在，计数不变）。

## 备注
- 当前 `sfx_*` 指向的音频文件尚未投放（占位期），故实际表现为「事件触发但静默」，待资源到位即出声；震屏 / 接任务已可立即生效。
- 新增事件只需在 `dialogue_events.json` 加键 + 在对话行 `trigger_events` 引用，无需改代码。
