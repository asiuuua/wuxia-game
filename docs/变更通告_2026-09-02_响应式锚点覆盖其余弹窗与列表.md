## 一、改动背景

派单 23a9d0b92b83（审计→UI）：当前仅部分界面做了响应式锚点，其余弹窗/列表在不同分辨率下可能错位。
本期统一收口：把「大视口保持设计尺寸、小视口自动内缩防溢出、分辨率变化自动重排居中」的响应式能力
覆盖到全部 PopupBase 派生弹窗 + 确认框 + 地图覆盖层 + 存档命名弹窗。

## 三、实现要点

- 统一走 `UICenterUtils.fit_panel_to_viewport`：自由面板设 size + custom_minimum_size 后按锚 0.5 + 对称 offset 居中；
  容器子节点仅靠 custom_minimum_size 让容器居中。
- `clamp_panel_size`：`min(desired, max(vp*(1-margin), 240))`，大屏零视觉变化，小屏防溢出，极端小屏不低于 240。
- headless 空安全：`get_viewport() == null` 时跳过接线（单测无真实视口），杜绝测试环境报错。
- 生命周期：`size_changed` 经 `tree_exiting` 断连，避免悬空监听。
