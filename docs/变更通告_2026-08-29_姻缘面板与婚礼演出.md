# 变更通告 · 姻缘面板 + 婚礼演出（M3 收口）

- 日期：2026-08-29
- 窗口：UI 模块（集成/收口）
- 前序：姻缘系统 M1（好感内核）/ M2（姻缘·婚姻·子嗣）已由结缘窗口落地、待收口；本通告完成 M3 的 UI 接入与演出接线，并把子嗣真正跑通。

## 一、交付内容（对应三件事）

### ① 姻缘面板 + 右上角按钮
- 新增 `scenes/ui/screens/bond_romance/BondRomanceScreen.gd`：纯代码构建 Control 面板，分五区（配偶/子嗣/结义/师徒/可发展），按钮调用 `BondService`/`RomanceService` 公开 API；刷新监听 `bond_relationship_changed`（0 参处理器，避免运行期崩溃）。
- `data/configs/ui/screens.json` 注册 `BondRomanceScreen` 条目（add-only 一行）。
- `scenes/ui/overlays/hud/Hud.gd` 右上角新增「姻缘」按钮（`UIFeedback` 悬停音效 + 红点：监听 `bond_relationship_changed` 经 `_refresh_romance_badge` 实时根据 `get_marriageable_npc_ids()` 点亮）。

### ② advance_days 接入时间流（子嗣跑通）
- `autoload/GameManager.gd` add-only 接线：监听 `EventBus.world_day_advanced` → 按天数增量 `romance_service.advance_days(delta)`；新游戏/读档同步天数基线 `_last_known_day`，避免子嗣孕期被错误快进。现睡眠/赶路推进天数后，怀胎十月真正分娩。

### ③ 结义 / 师徒 / 婚礼 公开 API + 婚礼演出
- `services/bond/bond_service.gd` 追加（只增，不破坏 M1/M2）：`can_swear/swear/get_sworn`、`can_become_apprentice/become_apprentice/can_take_apprentice/take_apprentice/get_master/get_apprentices`、`hold_wedding(npc_id)`（触发 `bond_wedding_started` 并返回 `wedding_scene` 路径）；`reset/save/load` 已含结义/师徒状态。
- `core/enums/bond_enums.gd` 追加 `WeddingType`（NORMAL/SIMPLE/GRAND）等。
- `autoload/EventBus.gd` add-only 新增信号：`bond_sworn_formed` / `bond_master_set` / `bond_wedding_started(npc_id, wedding_type, scene_path)` 等。
- `services/bond/romance_service.gd` 追加 `get_all_children()` / `get_marriageable_npc_ids()`。
- 新增 `scenes/gameplay/bond/WeddingScene.tscn` + `WeddingScene.gd`：婚礼演出场景（展示新人与婚礼类型，「礼成」返回主城）。`GameManager` 监听 `bond_wedding_started` → `change_scene_to_file` 进入；`BondRomanceScreen` 举办婚礼按钮在调用 `hold_wedding` 后关闭自身，避免覆盖层残留。
