# 整体验收标准（参考规范第六部分）

> 逐模块验收清单 + 整体验收标准。当前 Phase 1 切片仅覆盖玩家/背包/装备(部分)/武学/战斗/任务/NPC对话/存档，下方标注各模块可达状态。

## 各模块验收清单

### 玩家系统 ✅
- [x] 等级/经验/属性成长公式正确（`player_state.recalculate_stats`）
- [x] HP/MP 恢复与消耗正确
- [x] 金钱增减正确，不出现负数
- [x] 存档往返属性一致（ISaveable）
- [ ] 装备/武功/Buff 属性叠加（装备系统 Phase 2）
- [ ] 死亡/复活流程（Phase 2）

### 背包系统 ✅
- [x] 物品增删查正确（三包自动归类）
- [x] 堆叠/满包处理
- [x] 关键物品不可丢弃/出售（ItemFlag 位标记）
- [x] 材料箱自动归类、负重计算
- [ ] 排序/筛选/快捷栏（Phase 2 厚化）

### 武学系统 ✅
- [x] 学习条件校验、战斗栏装备/施放
- [x] 内功/外功数据驱动（`skills.json` + `learned_by_default`）
- [ ] 修炼升级/内功相克/走火入魔（Phase 2）

### 战斗系统 ✅

### 任务系统 ✅
- [x] 接取/交付、击杀/收集目标、奖励发放
- [ ] 前置依赖/分支/限时/追踪导航（Phase 2 厚化）

### 存档系统 ✅
- [x] 手动存档/读档、元数据、版本号、模块独立序列化
- [ ] 自动/快速存档、缩略图、大存档性能、损坏备份（Phase 2 厚化）

### NPC 对话 ✅
- [x] 数据驱动台词 + 动作（接任务/开战）

### 装备/锻造/炼丹/商店/门派 ⏸

## 整体验收标准（目标，分阶段达成）

### 功能性
- [ ] 所有 P0/P1 功能 100% 实现并通过测试
- [ ] 主线流程可无 Bug 通关

### 性能（红线见 `docs/跨模块通用规范.md` §6）
- [ ] 最低配置稳定 30fps；推荐配置 60fps
- [ ] 场景加载 <3s，启动 <5s；内存 <2GB；无内存泄漏

### 稳定性
- [ ] 连续 4 小时无崩溃；存档/读档 100 次无损坏；场景切换 100 次无崩溃
- [ ] P0/P1 Bug = 0

### 体验
- [ ] 战斗手感流畅（响应 <100ms）；UI 无卡顿
- [ ] 新手 30 分钟内理解核心系统；难度曲线合理
- [ ] 中文文本无错别字，文风统一

### 兼容性
- [ ] Windows 10/11 正常；1920×1080 ~ 3840×2160 正常
- [ ] 键鼠/手柄双输入；中英文切换（Phase 2 本地化）
