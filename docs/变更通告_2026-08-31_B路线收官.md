# 变更通告：B 路线（UI 全量 .tscn 化）收官

## 范围
原「UI 外观整改」决策（2026-08-30 拍板，经两轮反转后定）：保留上层编排架构（UIManager 六层 CanvasLayer、界面栈、窗口缓存、Toast 池、EventBus、双闸门、UIPalette/令牌），仅将叶子界面构造方式从 `script.new()`+`_build()` 改为 `.tscn` 实例化。上层架构与共享地基结构不变，只扩展值语义。

## 完成情况（截至 2026-08-31）
- 共享地基增量：screens.json 值语义由脚本路径改为场景路径——全部 21 个屏幕/弹窗均为 `.tscn`（0 个 `.gd`）；UIManager 按扩展名分流 `.tscn`/`.gd` 并改 `load().instantiate()`。
- 试点与逐屏迁移：InventoryScreen（全项目样板）→ 命名弹窗/设置顶部栏/HUD 状态卡 → HUD 四面板（任务追踪/右上菜单/技能栏）→ 主菜单底部栏 → 末组件 SaveCard（b8b06cc）。
- 动态列表（背包格/技能槽/商店行/对话选项等）按设计仍由代码 `instantiate` 模板 `.tscn`，B 路线下无法全消，属预期。

## 残留 `_build_ui()` 说明
经抽样核对（ShopScreen、ConfirmDialog 等），残留的 `_build_ui()` 或仅做按钮接线与磨砂皮肤套用，或构建动态数据列表；对应静态结构均已在 `.tscn` 中。故 B 路线「静态结构迁移」目标已 100% 达成。
