# 变更通告 · 登录背景布局控制（方案 B：游戏运行时读配置）

**日期**：2026-08-30
**模块**：登录主界面大背景（UIBackground 组件 + 工作室专业调教工具）
**性质**：功能新增（背景布局可配置 + 工具内实时预览）

---

## 一、用户痛点

替换登录大背景图后，即便用 1920×1080 的图也不满意：
- 游戏里背景写死 `STRETCH_KEEP_ASPECT`（等比不裁切），窗口比例与图不一致就**露边**；
- 露出的边用一块**写死的绿渐变垫底**填（从原版背景采样），换风格图后绿缝很难看；
- 暗化层、边色都不可调。

根因：布局行为全在游戏代码里，工具只能换图、改不了布局。

## 二、方案与决策

用户原选「只做工具、不动游戏代码」，但本需求下选择**方案 B**：小改 `UIBackground.gd` 让游戏运行时读取一份 JSON 配置（约 20 行，已过双闸门），实现：
- 与 Godot 原生 `TextureRect` 拉伸模式一致的布局预设（彻底还原「Godot 自己的背景布局页」手感）；
- 随窗口大小**实时自适应**，任意比例无黑边（大厂同款：背景 cover + 菜单落安全区，一套界面通吃 PC / 带鱼屏 / iPad / 手机）；
- 工具内**多设备比例实时预览**（A 方案的预览部分保留并增强为 4 种设备同屏预览）。

## 三、落地文件

游戏侧：
- `data/configs/ui/login_bg_layout.json`（新增）：`stretch_mode` / `scrim_alpha` / `edge_auto` / `leaves_enabled` / `edge_color`。默认 `keep_aspect_covered`(铺满裁切) + 暗化 0.55 + 自动取边色 + 落叶开。
- `scenes/ui/components/ui_background/UIBackground.gd`：新增 `@export var layout_config_path`；`_load_layout_config()` 按 JSON 覆盖运行时参数；`edge_auto` 时采样图片顶/底边缘色生成竖向渐变垫底（替代写死绿渐变）；`_build_image` 改用语 `stretch_mode`。向后兼容（路径为空保持原行为）。
- `scenes/ui/screens/main_menu/MainMenu.gd` 与 `scenes/ui/screens/save_load/SaveLoadScreen.gd`：给 UIBackground 实例设 `layout_config_path = "res://data/configs/ui/login_bg_layout.json"`。`LoadingScreen` 未动（其背景逻辑独立）。

工具侧（`tools/desktop_studio/`）：
- `studio_core.py`：`_login_bg_layout_path` / `login_bg_layout` / `login_bg_layout_update`。
- `studio_server.py`：`GET/POST /api/login/bg_layout`。
- `index.html`：登录界面标签页新增「🎛 背景布局（实时预览）」——预设按钮 + 暗化滑块 + 自动取边色/落叶勾选 + **4 设备比例同屏预览**（PC 16:9 / 带鱼屏 21:9 / iPad 4:3 / 手机 19.5:9）+ 保存布局。
- `工作室专业调教.spec` 沿用（带 `index.html` 内嵌）。
- `README.md` 补背景布局说明。

产物 exe：`dist/工作室专业调教.exe`（8220180 字节）已覆盖 Desktop + 工程 dist + 备份仓 `D:\工作室专业调教\`。
