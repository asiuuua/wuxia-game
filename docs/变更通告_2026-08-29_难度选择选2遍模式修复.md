# 变更通告 2026-08-29 · 难度选择选2遍模式修复

## 模块
UI 窗口

## 问题（用户报告）
- 登录界面每次点"开始"都要选 2 遍模式才能彻底进入游戏。

## 根因
- `DifficultySelect._proceed` 走的是 `UIManager.close_screen(self, func: GameManager.start_new_game)` 链：
  - 只关闭 DifficultySelect 自己；
  - MainMenu（压在 DifficultySelect 之下）**仍残留在 `_screen_stack`**；
  - `start_new_game` 内部 `change_scene_to_file(SCENE_TOWN)` 切场景；
  - UI 层的 CanvasLayer 是 autoload 挂在 `root` 上，**跨场景常驻不释放**；
  - 结果 MainMenu 继续渲染在 TownScene 之上，**遮挡 TownScene**；
- 玩家看到的是 MainMenu（6 个主菜单项）而不是 TownScene，以为"没进游戏"；
- 再次点"开始"→ 再开 DifficultySelect → 再选模式 → 才切场景（且 TownScene 切来切去）。
- 这就是"选 2 遍模式"循环。

## 复现验证
- 临时复现脚本 `tests/ui/regression_double_diff_select.gd`：
  - 修复前：`Right after _proceed, _screen_stack size=1, top=MainMenu` → 复现 BUG；
  - 修复后：`Right after _proceed (sync), _screen_stack size=0` → ✓ PASS。

## 修复
- `scenes/ui/screens/difficulty_select/DifficultySelect.gd`：
  - `_proceed` 改用 `UIManager.close_all_screens()` 一次性同步释放所有 UI 屏幕（含 MainMenu），再 `GameManager.start_new_game()`；
  - 与 `SaveLoadScreen._do_new_game` 行为一致（UI 入口自行清理 UI，符合主权边界）。

## 回归测试
- 新增 `tests/ui/regression_double_diff_select.{gd,tscn}`：
  - 完整链路验证：开 MainMenu → 开 DifficultySelect → 调 `_proceed('NORMAL')` → 同步断言 `_screen_stack` 为空；
  - **不进 `run_all`**：测试会触发 `start_new_game` 切场景，干扰其他套件；改成独立 tscn 跑。
- 跑法：`Godot_v4.7.2_console --headless --path "D:/武侠游戏" res://tests/ui/regression_double_diff_select.tscn`
