## 三、其他窗口写代码时的配合约定

1. **演出层只读 `CombatEvent` 播放**：血条 / 真气条一律按「行动后」字段直设，**禁止自己算差值或读 `CombatCharacter` 当前值**（加速 / 跳过 / 断线重连会错位）。
2. **加速 / 跳过语义**：加速 = 所有 duration ÷ `speed_scale`；跳过 = `speed_scale=999` + `set_instant(true)` 直接跳终态（不卡死）。卡死防护由 Director 的 `create_timer` 权威节奏兜底。
3. **时长令牌归属 UI 窗口**：所有演出时长走 `data/configs/ui/ui_anim.json` 的 `durations`（属 UI 窗口主权）。⚠️ **当前 `battle` 令牌块尚未提交**（UI 窗口 WIP 中），M2 未自改该文件，缺失时 Director 用 `_FALLBACK` 兜底。**请 UI 窗口补 `ui_anim.json` 的 `battle` 令牌块**（建议键：`instant/fast/normal/gentle/slow`）。
4. **ATB 顺序条只读不写**：消费 `CombatCore.action_order()`（按 `effective_charge_rate()` 降序），演出层不反向修改内核状态。
