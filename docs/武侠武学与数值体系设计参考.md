# 武侠武学与数值体系 — 设计参考

> 定位：本篇是面向本项目（武侠 RPG 战棋/实时战斗）的**武学系统与数值体系设计参考**，取自某现代"真武侠"风格武侠网游的成型体系，做去品牌化的拆解与提炼。
> 立场说明：以下数值、公式、机制均来自该作既有设定（口径差异以注释标出）；本项目落地时**全部按自身配置表二次重排**，切勿直接照抄权重，仅把"结构"和"拆法"当参考。

***

## 0. 一句话设计观

这套体系的核心不是"属性堆叠"，而是\*\*「招式相克 + 主动招架 + 内功属性联动」三者织成一张博弈网\*\*。数值只是让博弈"算得动"，真正决定手感的是招架/破招/连携那套出招节奏。落地时务必先立"招式克制框架"，再填数值。

***

## 1. 数值体系

### 1.1 角色基本属性（五大基础属性）

| 基础属性   | 逐点给予的换算                                     | 服务方向         |
| ------ | ------------------------------------------- | ------------ |
| **臂力** | 近身威力 +1；外功暴击 +1；气血上限 +2                     | 外功近身输出       |
| **身法** | 远程威力 +1；闪避 +1；外功命中 +1                       | 外功远程 + 回避    |
| **内息** | 内功威力 +1；内力上限 +4                             | 内功输出 + 内力池   |
| **罡气** | 内功命中 +1；内功暴击 +1；内力上限 +1；内力回复 +0.2；内功防御 +0.2 | 内功向的命中/暴击/续航 |
| **体魄** | 气血上限 +7；封劲 +0.5；气血回复 +0.3；招架耐力上限 +21        | 生存 + 招架耐力    |

> 重点：**副属性不靠"暴击率/命中率"单独一堆，而是三主属性各自派生成副属性**。这保证"加哪条属性"天然绑定"打哪种流派"，避免纯随机词条的无意义堆叠。臂力→外功暴击，罡气→内功暴击，身法→外功命中，这样"堆暴击"必须先选流派。

### 1.2 资源类属性

| 资源         | 说明                                         |
| ---------- | ------------------------------------------ |
| **气血（生命）** | 归零即重伤→休克；非战斗可缓慢回复（速度与**体魄**相关）；通过打坐/药品快速回复 |
| **内力（法力）** | 多数招式需消耗内力；非战斗缓慢回复（速度与**罡气**相关）             |
| **轻功值**    | 持续型轻功与部分招式会消耗；数值越高回复越快；冲刺也消耗轻功值            |
| **体力**     | 生活/生产类消耗资源；**每 5 分钟回复一次**，每日有回复上限          |
| **饱食**     | 影响体力回复速率；随时间自动消耗；靠食物补充                     |
| **杀戮值**    | 作恶行为的代价；高了触发追捕、重伤后入监，越高监禁越久                |

### 1.3 战斗副属性（二级属性）

| 副属性            | 来源         | 机制                          |
| -------------- | ---------- | --------------------------- |
| **闪避**         | 身法         | 影响他人打你的命中率                  |
| **封劲**         | 体魄         | 降低你被打出暴击的几率（防暴，区别于打折，是独立档）  |
| **外功招架**       | —          | 成功招架后减免**外功**伤害的百分比         |
| **内功化解**       | —          | 成功招架后减免**内功**伤害的百分比         |
| **外功防御**       | 装备         | 减少所受外功伤害                    |
| **内功防御**       | 罡气（+0.2/点） | 按比例降内功伤害；量级：约 12 点降 1% 内功伤害 |
| **近身威力**       | 臂力         | 提高近身外功招式伤害                  |
| **远程威力**       | 身法         | 提高暗器等远程套路伤害                 |
| **内功威力**       | 内息         | 提高内功招式伤害                    |
| **外功命中**       | 身法         | 提高外功攻击命中率                   |
| **内功命中**       | 罡气         | 提高内功攻击命中率                   |
| **外功暴击**       | 臂力         | 提高外功暴击率                     |
| **内功暴击**       | 罡气         | 提高内功暴击率                     |
| **招架耐力**       | 身法 + 体魄    | 招架时消耗；耗空→破防，一段时间无法招架        |
| **刚/柔/阴/阳 防御** | 罡气         | 分别减少对应属性伤害                  |
| **破防能力**       | 武器特属       | 忽视对手外功防御（独立于招架条的穿透）         |

> 设计启示：**内外功是两套平行的"命中/暴击/威力/招架"**（外功由身法/臂力主导，内功由罡气/内息主导），攻防两端都对应"外/内"两份。这让"堆装备"对流派有清晰签名，也让"招架流派克制"（外功靠外功招架、内功靠内功化解）天然成立。

### 1.4 伤害类型与颜色标注

- **伤害分类**：外功伤害 / 内功伤害；再按元素切为 **刚、柔、阴、阳** 四属性（加一个 **太极** 作为中间态）。

- **招式加成三色标注**：招式面板的基础伤害之外，会带

  - 🔴 红色 = **臂力**加成部分

  - 🟢 绿色 = **身法**加成部分

  - 🔵 蓝色 = **内息**加成部分

  - 不同套路的每个招式，三者加成比例各不相同；多数"怒气大招"是"臂力+内息"双加成且比例很高。

- **点评**：用"红绿蓝"给玩家可读的数值来源，让"这个招吃哪条属性"一眼可懂——这是优秀的数值可读性设计，本项目 UI 可直接借鉴。

## 2. 武学知识体系

### 2.1 招式的五行（属性）倾向

每个招式都带一个**属性倾向**：**阴 / 阳 / 刚 / 柔 / 太极**。

- 使用该招式时，若你**当前运行（激活）的内功与招式属性相同**，则该招威力获得加成。

- 一套招式往往整体偏向某种风格，靠内功联动放大。

> 这是"内功↔招式"的纵向耦合：**练一次内功，能加成一整类属性相符的招式**。比"每个招单独点等级"少了很多操作负担，同时内功选择变成流派分水岭。

### 2.2 属性签名

- **臂力/身法/内息** 三者还会对"不同招式"产生不同的伤害加成（不只是基础公式），即**招式的属性签名**是由"基础伤害 + 某种主属性加成 + 五行属性"组合而成。

## 3. 战斗规则核心：招式类型与克制

### 3.1 套路（武学组合）构成

每个\*\*套路（武学）\*\*包含一组招式，标准配置含完整结构：

- **实招**：绝大多数攻击主招，主要输出手段

- **虚招**：专用于**破除对方招架**；攻击力较弱

- **架招**：施加到自身、增加招架效果；**只能同时存在一个架招**；配合主动招架成功时才能发挥特殊效果

- **气招**：多为"增强自己 / 削弱对手"，偶有攻击招

> **招式类型之间存在相生相克关系**——这是整套战斗节奏的支点："对方架→我用虚；我要稳→我先架；抢输出→实；控场或起 buff→气。"

### 3.2 主动招架（核心交互）

1. 只有**进入战斗状态**才能招架（有独立绑定键）。
2. 招架状态**移速 -70%**（代价明显）。
3. 成功招架→受到的伤害**大幅减免**；减免幅度：

   - 外功伤害 → 看**外功招架**

   - 内功伤害 → 看**内功化解**
4. 成功招架 → **获得怒气**（怒气主要来源之一）。
5. 成功招架 → **消耗招架耐力**；耐力上限与恢复速度联动基础属性，消耗量还与**攻击方的攻击强度**有关。
6. 耐力为 0 → 进入**破防状态**，一段时间内无法招架。
7. **虚招命中 → 破除招架并进入破防状态**。

> 简言之：防御(架) ⇄ 交换(怒气/减伤)；克制(虚破架)；代价(移速/耐力)。"破防"是攻防转换分水岭，也是连招入口。

### 3.3 连招与节奏

- **预备招**：在攻击范围外可先按出招式，进入一段"预备"；跑进攻击范围并满足释放条件即自动出招（只对锁定目标招式生效）。招式一释放后可立刻预备招式二，招式一动作播完，预备的招式二自动连上 → 边跑边压节奏的连锁手感。

- **自动冲刺**：范围外使用带"可用轻功快速接近对手"关键字的招式，可自动冲刺进身攻击。冲刺消耗**轻功值**，距离与**轻功种类/等级**相关，冲刺**可被对方轻功躲闪**。

- **连招拆法**（反打思路）：「架招起手（格挡滚出护盾）→ 缓冲 → 反打主力 → 位移/收割」，整套以"先吃伤害换护盾，再反打"组织，说明连招设计常围绕"防御换资源→进攻泄资源"的轴。

### 3.4 冷却规则

- **公共冷却**：招式与招式之间 1 秒公共冷却。

- **套路间切换冷却**：切换不同套路的招式有切换冷却，不同套路冷却不同；个别"三脚猫"类不受此限。

## 4. 内功系统

### 4.1 内功特征（以一口江湖内功为例）

- **属性面**：直接加基础属性（如：臂力 +19、身法 +16、内息 +139、罡气 +65、体魄 +18）。

- **运行激活**：提供常驻面板加成（如：气血上限 +2840、内力上限 +855、太极属性招式伤害 +20%、刚/阳/阴/柔属性招式伤害 +16%）。

- **内功特效**：带条件触发的特殊机制（如：每次攻击给目标注入一股真气，累计 10 股后使其"筋脉紊乱"——即"叠层触发负面"）。

> 结构三层：**基础属性值 + 运行激活面板 + 条件特效**。前两层可离开战斗静态结算，第三层进战斗引擎——这是可落地性很高的分层。

### 4.2 经脉修炼

- 习得基础吐纳功（如"坐忘功"，新手任务即可学的江湖内功）后，**开通九条经脉**。

- 每条经脉在未突破上限前，**最多修炼 9 周天**。

- **门派内功修炼到对应层数→开通对应穴位**，穴位与经脉联动，构成"内功层数→穴位→经脉"的纵向养成链。

> 启示：养成纵深 = 被一个基础技能解锁的九条经脉 × 每条最多 9 周天 × 门派内功层数开的穴位，用"上限 + 周天"制造长线，用"穴位解锁"制造阶段里程碑。

## 5. 武学获取与分级

| 层级       | 获取          | 定位                      |
| -------- | ----------- | ----------------------- |
| **门派套路** | 入门派、满足条件即可学 | 易获得、循序渐进、带流动传承、鲜明反映门派风格 |
| **江湖套路** | 仅江湖奇遇可得     | 难度高、效果多样、风格迥异、威力普遍更佳    |
| **镇派武学** | 门派至高传承      | 集武学之大成，通常是门派的招牌合体套路     |

- 套路威力可**消耗修为**提升招式威力；不同套路可提升的次数与每档威力各不相同（"上限 + 档位"建模）。

## 6. 招式设计卡（字段拆解）

来源：真实招式面板背后的统一字段结构。设计本作招式时，推荐直接采用如下"招式字典"，每个招式是一条记录。

| 字段                  | 说明                                      |
| ------------------- | --------------------------------------- |
| `id / 名称`           | 招式唯一标识；名称走武侠意象（如"白鹤亮翅""追星赶月"）           |
| `type`              | 实招 / 虚招 / 架招 / 气招                       |
| `affinity`          | 阴 / 阳 / 刚 / 柔 / 太极（联动内功）                |
| `range`             | 判定：近多攻 / 远多攻 / 单体 / 群体；数值范围（米）          |
| `cooldown`          | 本招冷却（另受公共冷却 1s 约束）                      |
| `inner_cost`        | 内力消耗                                    |
| `light_kungfu_cost` | 轻功值消耗（若有自动冲刺则要消耗）                       |
| `damage`            | 基础伤害 + 臂力/身法/内息 各自加成系数                  |
| `on_hit_effect`     | 命中附加状态（如"黏劲：移速 -10%，可叠 2 层，持续 10s"）     |
| `special`           | 前置条件（如"自身存在'宫'时，招式可击落空中目标"）、架势联动、击落/浮空等 |
| `weapon_bind`       | 武器适配（装备某种武器发挥 100%，他种只发挥 70% 等）         |
| `power_ladder`      | 修为所提升的威力档位（档数与单档增量）                     |

## 7. 对项目落地的映射建议

本节是"扒"来体系后，回到本作战棋/战斗的实际落地护栏：

1. **先做"招式克制"再调数值**：实/虚/架/气的相克是手感来源，先在战棋里做成"出招判定 + 破防窗口"，数值其次。
2. **"内功 ∝ 招式属性"做成配置联动**：内功对象持有 affinity\_bonus 映射，招式按 affinity 查加成，避免硬编码。
3. **内外双轨副属性**：在属性表里为"外功/内功"各开一套命中/暴击/威力/招架来源，保证流派签名清晰。
4. **三层内功**：基础属性值（离线结算）＋运行激活面板（离线结算）＋条件特效（战斗引擎），三层各自独立可配。
5. **招式字典落地**：直接以 §6 字段建 moves.json 系列表，比散落技能脚本更易维护与追数。
6. **数值来源可视化**：玩家面板/招式卡给"红绿蓝"加成来源标注，提升数值可读性。
7. **养成纵深借鉴**：以"基础功法解锁经脉 → 门派内功层数开穴位 → 周天上限"做长线目标，每步给阶段回馈。

## 8. 附：关键公式/口径速查

- 臂力 1 点 → 近身威力 +1、外功暴击 +1、气血上限 +2

- 身法 1 点 → 远程威力 +1、闪避 +1、外功命中 +1

- 内息 1 点 → 内功威力 +1、内力上限 +4

- 罡气 1 点 → 内功命中 +1、内功暴击 +1、内力上限 +1、内力回复 +0.2、内功防御 +0.2

- 体魄 1 点 → 气血上限 +7、封劲 +0.5、气血回复 +0.3、招架耐力上限 +21

- 内功防御约 12 点 = 降低 1% 内功伤害

- 公共冷却 1s；招架状态移速 -70%；招式五行属性五类（阴/阳/刚/柔/太极）

- 经脉每条最多 9 周天（未突破上限）；九条经脉
