```

```
- **必须串行**：禁止与编辑器 / 其他 Godot 进程同时跑，多进程抢 `.godot` 类缓存会级联假红。
- **缓存坏先重建**：怀疑 `Could not resolve script` / `X not declared` 类报错时，先
  `"<godot_console>" --headless --editor --quit`（约数秒重建 `global_script_class_cache.cfg`）再跑双闸门。
- **绝不要 `rm` 删 `.godot`**：删后 `--quit` 模式不写缓存，GATE1 会全红（本会话已踩过）。重建用 `--editor --quit`，不要删。
- 镜像路径必须 Windows 风格 `D:/武侠游戏`；POSIX `/d/...` 会让 Godot 静默不跑（门禁误报绿）。
- `get_tree().quit(code)` 退出码不传播 → 以 `run_all` 的 `✗` 标记判成败，不靠进程码。

### 3.2 git 操作

- **沙箱 git 写不落盘**：本机 Bash 工具在沙箱内运行，`git commit/push/checkout/rm` 等写操作不落真实磁盘。写操作必须 `dangerouslyDisableSandbox: true`。
- **中文路径 `git add` 坑**：显式 `git add "docs/变更通告.md"` 会因命令行中文匹配失败导致整条 add 失败。工作树仅含项目正当改动（`.godot` 已 gitignore、无构建产物）时，直接用 `git add -A`（与桌面 `wuxia-git-sync.bat` 一致）；若需精确，用 `git add -u` 暂存已跟踪修改 + 显式加未跟踪英文路径。
- **令牌推送**：用临时 URL，`git push "https://<user>:<TOKEN>@gitee.com/asdf1328886661/wuxia-game.git" master`；推完确认 `git remote get-url origin` 不含令牌（`https://gitee.com/asdf1328886661/wuxia-game.git`）。令牌**绝不写进 git config / 文件 / 记忆**。
- `git status` 的 `upstream is gone` 只是本地 tracking 提示噪音，`git push origin master` 不设 upstream，无害。
