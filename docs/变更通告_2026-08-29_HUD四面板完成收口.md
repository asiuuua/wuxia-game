## 三、共享地基增量（EventBus 纯追加，未改任何既有信号）

| 信号 | 参数 | 用途 / 产生方 |
|---|---|---|
| `notify_quest_track_changed` | 无 | 任务追踪列表变化（接取/交付/重置）；任务窗 `quest_service` 在 `accept`/`turn_in`/`reset` emit |
| `notify_skill_bar_changed` | 无 | 快捷栏武学装备变化；武学窗 `ability_service` 在 `equip_combat_skill`/`unequip_combat_skill` emit |
| `notify_skill_cd_update` | `skill_id: String, remain_time: float` | 快捷栏武学冷却读秒；武学窗 `ability_service` 在 `set_cooldown`/`tick_cooldowns` emit |

铁律遵守：仅**追加**信号，未修改/删除任何既有信号；各信号声明于 `EventBus.gd` 的
「HUD 常驻系统（UI 窗口主权 · 共享地基纯追加）」段，并配 `@warning_ignore("unused_signal")`。
emit 责任归属产生方（任务窗 / 武学窗），UI 窗口只订阅消费。

## 五、生命周期与防回归

- `Hud.gd` 仅 `_ready` 中 `add_child` 四面板，自身零订阅、零业务刷新逻辑（配色/布局全下沉各面板）。
- 四个面板各自 `_exit_tree` 断开 EventBus 订阅，并 `is_instance_valid(EventBus)` 判空，
  防切场景 / 退出时 EventBus 先释放导致 "Trying to cast a freed object"。
- `quest_track_panel._refresh` 全量重建 `_entries`，清旧条目用 `free()` 立即释放，避免 `queue_free` 幽灵节点。
- 面板读服务数据均走只读 + null 守卫（`is_instance_valid(GameManager)` 且 `xxx_service != null`），
  服务未初始化时不崩、仅空渲染。
