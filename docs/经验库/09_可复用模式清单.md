# 09 · 可复用模式清单（跨项目 / 跨窗口）

> 检索关键词：可复用、模式、事务、单一真源、门面、发号器、预检、平台能力、经验
> 等级：E3

## 提炼自本工程、可迁移到任意 Godot/单机 RPG 的模式

### 1. 事务化资产 API（经济/资产守恒）
- **模式**：任何「扣 A 给 B」操作 = 先预检（can_add / get_unlocked_count）再 apply，失败回滚；原子扣料聚合 `need_by_id` 全量校验。
- **锁死**：扣钱不发货、扣料丢产出、售卖锁定物换钱。
- **复用**：任何含背包/货币/合成的系统直接套 `InventoryTransaction` 思路。

### 2. 单一真源（防脏档）
- **模式**：某类状态只一处持有（好感度→BondService、配偶→RomanceService、结义/师徒→Sworn/Master）；查询走聚合门面。
- **锁死**：双写不同步（BUG-03）。
- **复用**：任何「多模块都要看的同一份状态」都下沉唯一真源。

### 3. 纯聚合门面（回城编排）
- **模式**：`RelationshipService` 自身无状态/不进存档，只读各服务公开方法拼统一视图；新增关系类型只补 `_node_of`，UI 零改。
- **复用**：关系网/总览/右上角角标等聚合展示。

### 4. 实例 ID 发号器
- **模式**：`_next_iid` 全局自增 + 随存档恢复，实例身份稳定（装备耐久/锁定不丢）。
- **复用**：任何需稳定实例身份的系统（物品/实体）。

### 5. 预检再应用（两段式）
- **模式**：`query_add`/`can_add` 纯计算不改状态；apply 前必调。
- **复用**：背包满/材料足/等级够等所有前置校验。

### 6. 逻辑/视图接缝
- **模式**：逻辑纯 `RefCounted`（不持 Node），视图 `_draw()` 程序化绘制；高频流走返回值，跨模块通知/视图更新才走 EventBus。
- **复用**：战斗/任何需 headless 可测 + 切场景存活的系统。

### 7. 双闸门 + 静默接缝四层防线
- **模式**：GATE1(headless 零错误) + GATE2(单测零✗) + GATE0(静态扫描) + 启动卡口令。
- **复用**：任何项目的提交前回归与静默 BUG 防御。

### 8. 连接器而非容器（平台）
- **模式**：平台只对接工程、不持有工程数据；`ai_context`/`reskin`/`knowledge` 三段复用经验。
- **复用**：多项目并行、换皮不换药、新 AI 秒懂架构。

## 给平台/新项目的落地
- 事务化资产 API、单一真源、门面聚合 → 进「项目脚手架模板」。
- 双闸门/静默防线 → 进「CI/提交门禁模板」。
- 连接器三段 → 进 `manifest.yaml` 模板（见 `10_平台连接器三段_ai_context_reskin_knowledge.md`）。
