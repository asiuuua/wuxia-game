## 二、本轮改动清单（按主权归属分组）

### A. UI 窗口主权内（其他窗口请勿改这些文件）
- `scenes/ui/screens/settings/SettingsScreen.gd`：**整体重写**为独立弹窗（非全屏 Control）。结构：
  - 压暗遮罩 `Backdrop`（`UIPalette.DIM`，`MOUSE_FILTER_STOP`，点外部→`_go_back()` 关闭）；
  - 居中磨砂玻璃 `Panel`（`UIPalette.GLASS_BG` StyleBoxFlat：圆角 14 / 细白边 `GLASS_BORDER` / 阴影 18 + 偏移 / content_margin 留白），`_fit_panel()` 自适应居中（`mini(vp.x*0.92,960)` / `mini(vp.y*0.90,680)`）并连 `get_viewport().size_changed` 重新限位，避免分辨率/窗口缩放后出界错位；
  - `Header`（返回按钮 + 金色标题 `settings_title` + 重绑提示，返回按钮走 `_apply_glass_button_style`）；
  - `Body`（HBox：左 `CategoryList` 180 宽 + 右 `ScrollContainer` + `_panel_vbox`，header 下偏移 64）。
  - **三种关闭**：返回按钮 / `ui_cancel`(ESC，顶层守卫 `get_current_screen()==self` 仅栈顶响应) / 点遮罩。
  - **语言切换 `_rebuild_ui` 只重建内部**：刷新左侧分类按钮文案（按各自 cat 重新 `tr()`）+ 重建右面板，不动弹窗框架/遮罩（修复旧版 `_category_buttons=[]` 清零导致语言切换文案不刷新的静默 bug）。
  - `_apply_glass_button_style(btn, font_color)`：磨砂玻璃按钮对齐 ConfirmDialog（normal/hover/pressed/focus 四态 StyleBoxFlat，font_hover→TEXT_MAIN），全工程按钮样式统一。
  - 颜色全走 `UIPalette`；字号走 `FS_HEADER/FS_SUB/FS_SMALL`。五分类（音频/画面/控制/游戏/语言）滑块/下拉/开关/键位重绑定均实时生效并自动持久化 `user://settings.json`。
- `scenes/ui/screens/main_menu/MainMenu.gd`：`_on_open_settings()` 改 `UIManager.open_screen("SettingsScreen", FULLSCREEN)` → `UIManager.show_popup("SettingsScreen")`（弹窗叠主菜单之上，而非关掉主菜单再开全屏）。
- `scenes/ui/screens/esc_menu/EscMenu.gd`：`_open_settings()` 改 `close_screen(self, func(): open_screen FULLSCREEN)` → `UIManager.show_popup("SettingsScreen")`（弹窗叠 ESC 菜单之上，关闭后回 ESC 菜单）。
- `autoload/settings_manager.gd`：`apply_graphics()` **分辨率/窗口模式生效加固**——先退出全屏到窗口态再 `window_set_size`，最后再置最大化（全屏态下 `window_set_size` 无效，是此前"切窗口分辨率不生效"的根因）。`render_scale`（3D 渲染分辨率）与 `ui_scale`（UI/文字大小）保持独立两设置、互不污染（已在 2026-08-29 早轮回合落地，本轮无回归）。

## 三、其他窗口写代码时的配合约定

1. **打开设置统一用 `UIManager.show_popup("SettingsScreen")`**：弹窗叠在底层界面（主菜单/ESC）之上，不要再用 `open_screen(FULLSCREEN)` 把底层关掉再开全屏。
2. **独立弹窗范式**：新增同类弹窗应沿用「Backdrop 压暗遮罩 + 居中 Glass Panel（`UIPalette.GLASS_BG` 磨砂玻璃）+ 内部 header/body + 三关闭」范式（参考 ConfirmDialog 与 SettingsScreen）；不要再用"全屏 Control + 主菜单式背景"做法。
3. **磨砂玻璃按钮样式统一 `_apply_glass_button_style`**，对齐 UIPalette + ConfirmDialog；不要在脚本里写裸色值/裸字号。
4. **分辨率/窗口模式生效逻辑只在 `settings_manager.apply_graphics` 内**，调用方不要自调 `DisplayServer.window_set_*`（`window_set_size` 必须先在窗口态、全屏态下无效，顺序错会静默不生效）。
