## 三、其他窗口写代码时的配合约定

1. **开战统一走事件总线**：任何模块要触发战斗，`emit EventBus.cmd_start_combat.emit(attacker_list, defender_list)`；由 GameManager 解析 NPC→`battle_id` 开战。**不要**再直调 `GameManager.start_battle`（那是内部入口）。
2. **任务阶段以 GameState 为真源**：读取走 `GameState.get_quest_phase()` 或 `quest_service.get_phase()`；推进走 `advance_quest_phase()`。禁止自己另存一份 phase。
3. **呼吸动画约定**：角色 Node2D 原点钉脚底，身子（Sprite2D / 占位 ColorRect）打 `body` meta；缩放用 `body.scale`（绕 `pivot_offset` 中心），**不要**缩放整个 Node2D（会连带阴影/相机）。GS 如需加新动效，参数进 `ui_anim.json` 的 `breath` 块。
4. **内容新增只增条目**：往 enemies / battles / items / skills / quests 等加内容时保持既有条目不动；若新增战斗/敌人被本窗口任务引用，确保 `battle_id` / `enemy_id` 双向存在。
