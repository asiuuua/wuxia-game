## 二、本窗口主权新增（战斗窗口 · scenes/gameplay/battle/）

| 文件 | 职责 |
|------|------|
| `battle_grid_node.gd` | 等轴测网格视图（`class_name BattleGridNode`）。`_draw()` 程序化绘制菱形地形（可走/障碍）+ 高亮层（蓝=可移动 / 绿=敌威胁 / 红=技能范围）；订阅 `EventBus.grid_highlight_update`；提供 `cell_center/world_to_grid/pixel_center` 供实体落位与点击拾取。**不依赖任何 TileSet/贴图资产，headless 可编译。** |
| `battle_entity.gd` | 单位实体（`class_name BattleEntity`）。占位精灵 + 头顶悬浮血条/真气条 + 选中环 + 飘字；`place_at` 立即落位、`move_to` Tween 插值（GRID_MOVE 事件驱动）；`set_hp/set_mp` 据事件直设（与 M2 演出约定一致）。 |
| `tactical_battle_scene.gd` | 战术战棋场景（`class_name TacticalBattleScene`）。装配战场（Camera2D 居中 + 网格 + 实体）→ 四角 HUD（左下我方状态 / 右下目标卡 / 右上战场条件+自动开关 / 底部行动栏，**本窗自绘，不碰全局 HUD 主权**）→ 输入状态机（IDLE→选行动→AWAIT_TARGET→执行）→ 回合驱动（玩家行动 → 敌方阶段复用 `enemy_tactical_plan` 走位 + `enemy_act_events` 结算）→ 自动战斗（走近最近敌人→普攻，带回合上限）。 |
| `TacticalBattleScene.tscn` | 场景入口（Node2D 根 + 脚本），供 `change_scene_to_file` 路由。 |

## 三、数据流（视图层不持逻辑）

```
GameManager.start_battle(tactical) → TacticalBattleScene
  └─ combat_service.start_combat → 内部按 battles.json 的 tactical+grid 构建 BattleGrid 并部署单位
  └─ 场景读 combat_service.get_grid() / get_state() 建表现层
  └─ 玩家点击 → compute_reachable / compute_skill_range / move_unit / player_*_events（全走 CombatService 门面）
  └─ 敌方阶段 → enemy_tactical_plan + enemy_act_events（与玩家共用同一套内核结算）
  └─ 事件流 → _play_events 直设 BattleEntity 血条/真气 + 飘字 + GRID_MOVE 驱动 Tween
  └─ 结束 → combat_service.finalize → 结果面板 → 返回城镇
```

## 九、用户运行时反馈：棋盘斜45度 + HUD/棋盘全鼠标失灵（修复 提交 b50465f）

- 现象：编辑器运行后棋盘呈斜45度等轴测、未居中；HUD 四个角面板按钮全点不动；点棋盘也移动不了单位、技能放不出。
- 根因①（斜45度/不居中）：`battle_grid_node.gd` 初版用等轴测换算 `world=((gx-gy)*tw/2,(gx+gy)*th/2)` 画菱形，且战术场景挂了 `Camera2D` 居中，整体呈斜向。
- 根因②（全鼠标失灵）：HUD 全屏根 `Control` 未显式设 `mouse_filter`，默认 `MOUSE_FILTER_STOP` —— 全屏 STOP 会吞掉所有鼠标事件，导致点棋盘（走 `_unhandled_input`）与点按钮（`pressed`）均被拦截而全部失灵。
- 修复：
  - `battle_grid_node.gd`：弃用等轴测，改平整方格坐标 `cell_center=(p.x+0.5)*cell_size`，`_draw()` 直接用 `draw_rect` 画每格（可走/障碍两色），`world_to_grid` 按 `int(world/cell_size)` 反算。棋盘平整。
  - `tactical_battle_scene.gd`：移除 `Camera2D`，改 `_build_world` 用 `bf.position = 屏幕中心 - grid.pixel_center()` 把平整战场居中；HUD 根 `Control`、面板 `_panel()`、行动栏 `bar` 均显式设 `MOUSE_FILTER_PASS` 透传鼠标；按钮（普攻/技能/物品/结束/自动）设 `MOUSE_FILTER_STOP` 拦截自身点击、阻止透到棋盘。点击拾取仍经 `_unhandled_input → grid_node.to_local(get_global_mouse_position()) → world_to_grid` 反算。
- Gate1 `--quit` 零 SCRIPT/PARSE/COMPILE ERROR 复验通过。
- 注：视图层 headless 不可单测，上述为运行时表现修复，需用户本机 F5 复跑确认手感。
