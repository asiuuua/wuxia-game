## 一、本次交付内容

在 M1 共用好感度内核之上，长出**姻缘 / 婚姻分支**（`RomanceService`），实现你要求的：

1. **送礼物 → 好感满 100（倾心）→ 结缘**：求婚 `propose()` 校验「可结缘 + 异性 + 好感满 + 非配偶」后写入配偶名单并推进到已婚阶段。
2. **无限配偶（不限制数量）**：配偶以 `npc_id` 为键存 `Dictionary`，天然无上限——玩家可同时拥有任意数量的 NPC 妻子/丈夫。
3. **异性校验**：读 `relations.json` 的 `required_gender`，与 `PlayerState.gender` 比对；`required_gender < 0` 表示不限制性别。
4. **数据驱动、小白可配**：新增一个可结缘 NPC 只需在 `relations.json` 复制一段并设 `is_romanceable: true` + 礼物列表（见第五节），**不碰任何代码**。
5. **子嗣预留数据层（寝欢 + 怀胎十月）**：`begin_intimacy()` + `advance_days(n)` 已实现完整链路（孕期 300 游戏日、到期分娩、记录子嗣、广播 `bond_child_born`）；时间源解耦为 `advance_days(n)`，待 `TimeService` 或「休息/睡觉」动作接入后自动生效。

## 五、小白配置指南（以后加可结缘 NPC 只改这一个 JSON）

在 `data/configs/bond/relations.json` 的 `relations` 数组复制一段：

```json
{
  "id": "npc_xin_npc",
  "name": "新角色",
  "gender": 1,
  "is_romanceable": true,
  "required_gender": 0,
  "loved_gifts": ["pill_heal_dahuang_001"],
  "liked_gifts": ["material_silk_raw_001"],
  "disliked_gifts": ["material_ore_001"],
  "max_affection": 100,
  "romance": { "propose_affection": 100, "wedding_type": "NORMAL", "dowry_required": [], "spouse_ability": "", "allow_multiple": true }
}
```

- `is_romanceable: true` 总开关；`required_gender` 限定玩家性别（0 男 / 1 女 / -1 不限）；`loved/liked/disliked_gifts` 决定送礼好感；`romance` 块可选（有默认）。
- 玩家在游戏里对该 NPC 送礼把好感刷到 100，即可结缘；数量不限。
