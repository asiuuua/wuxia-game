# 变更通告 · 登录主菜单各按钮背景图（方案 B 续：游戏读取映射）

**日期**：2026-08-30
**模块**：登录主菜单 MenuItem 按钮背景（MenuItem 组件 + MainMenu + 工作室专业调教工具）
**性质**：功能新增（工作室工具存的按钮背景图，现在会在游戏内渲染）

---

## 一、背景

工作室工具（登录界面标签页「🎴 各按钮背景图」）早已能把每个主菜单按钮的图存到
`assets/ui/main_menu_btn/<menu_* 键>.png`，并在 `data/configs/ui/login_button_bg.json` 登记映射，
但**游戏代码不读这张表**——图存好了却只在工具里能看到，进游戏仍是无背景的浮动文字。

上一轮已落地的登录大背景布局（方案 B：运行时读 JSON）让背景图能自适应，本功能是其自然延伸：
按钮背景图也应「工具存、游戏读」，打通最后一公里。

## 二、落地文件

游戏侧：
- `scenes/ui/components/menu_item/MenuItem.gd`：
  - 新增 `var _bg: TextureRect` 与 `var _pending_bg_path: String`；
  - 新增 `set_background(bg_path: String)`（在 add_child 前调用，类似 set_text 的暂存模式）；
  - `_configure_nodes()` 末尾：若 `login_button_bg.json` 命中该菜单项的 `menu_*` 键，则创建一张**铺满按钮**的 `TextureRect`（`PRESET_FULL_RECT` + `STRETCH_KEEP_ASPECT_COVERED`，置底 `move_child(_bg, 0)`），其上叠一层轻压暗 `ColorRect`（alpha 0.25，保证米白文字可读）；
  - 缺图 / 缺键则跳过（向后兼容，旧菜单表现不变）。
- `scenes/ui/screens/main_menu/MainMenu.gd`：
  - 新增 `const BTN_BG_MAP_PATH` 与 `_load_btn_bg_map()`（`FileAccess` 读 JSON 的 `map` 字段，文件/字段缺失返回空字典）；
  - `_build_menu()` 在 `set_icon` 后按 `MENU_ITEMS[i]["text"]`（即 `menu_new_game` 等键）查表，命中即 `item.set_background(map[键])`。

工具侧（`tools/desktop_studio/`，上一轮已具备，本轮回写提示文案）：
- `index.html`：按钮背景图区提示由「需一小段代码变更才会在游戏内显示」改为「游戏代码现在已读取此映射，上传后下次进主菜单即生效」。
- 数据落点不变：`assets/ui/main_menu_btn/<键>.png` + `data/configs/ui/login_button_bg.json`（`map` 字段，`res://assets/ui/main_menu_btn/<键>.png`）。

产物 exe：`dist/工作室专业调教.exe`（8221764 字节）已覆盖 Desktop + 工程 dist + 备份仓 `D:\工作室专业调教\`。

## 三、验证（双闸门）

- GATE1：`--headless --path --quit` 零 `SCRIPT/PARSE/COMPILE ERROR`（仅 `main_menu_bg.jpg` 资源加载提示，属已知资产导入期噪声）。
- GATE2：`run_all.tscn` **全部子套件 失败 0**（共 41 个小计块全部 0 失败）。
- 工具冒烟：重装 exe 后 `GET /api/login/btn_bg` 返回 6 个主菜单项；首页含更新后的提示文案；关闭无残留进程。

> 注：实现中曾误用 `TextureRect.EXPAND_FIT`（本 Godot 构建无该成员，导致 MenuItem.gd Parse Error 并级联出 set_icon 报错），
> 已改为仅用 `PRESET_FULL_RECT` + `STRETCH_KEEP_ASPECT_COVERED` 实现铺满裁切，`expand_mode` 对全矩形背景本就无关，双闸门复测全绿。

## 四、给用户的操作提示

1. 双击 `工作室专业调教.exe` → 浏览器 `http://127.0.0.1:8765/` → 登录界面标签页 → 「🎴 各按钮背景图」；
2. 给每个按钮上传一张图（建议透明 PNG 或带圆角/底色的图，铺满裁切）；
3. 进 Godot 按 F5 进主菜单：对应按钮即显示你上传的背景图（图下压一层轻暗，文字仍清晰）；
4. 想去掉某按钮背景：在工具里把那张图删掉（或清空映射），游戏侧会自动回退到无背景。
