## 一、新增 `core/streaming_media_loader.gd`（class_name StreamingMediaLoader，纯静态工具）
- 封装 `ResourceLoader.load_threaded_request / get_status / get` 的后台线程异步加载，**非阻塞**发起、调用方轮询取用。
- API：`request(path, type_hint, use_sub_threads)`（非阻塞发起）、`get_status(path)`、`is_ready(path)`、`is_failed(path)`、`take(path)`（就绪后取资源）、`load_blocking(path, type_hint)`（便捷同步）、`cancel(path)`。
- 状态常量对齐 `ResourceLoader.THREAD_LOAD_*`。对齐 PortraitCacheManager / CombatEntityPool 模式：**纯工具 + class_name，不注册新 Autoload、不碰共享地基**。

## 二、CG 流式播放（CelebrationOverlay · 结缘窗口主权内）
- `_apply_media` / `_play_bgm` 改为经 `ResourceManager.acquire_async` 异步加载；加载完成回调 `_on_media_ready` / `_on_bgm_ready` 再建播放节点（按资源实际类型 VideoStream / Texture2D / AudioStream 分支）。
- **非阻塞**：台词/文字立即显示，重资源（CG 视频数十 MB）后台线程加载完成后"流式"补位，不再 `load()` 同步卡开场。
- 降级：加载失败（如不支持的视频编码）静默跳过，仅留文字，不崩。

## 三、逐行语音（AudioManager · 音频主权内，纯追加）
- 新增 `play_voice(path)`：经 `ResourceManager.acquire_async` 异步加载语音，完成回调 `_on_voice_loaded` 接流播放（音量按规范 VOLUME_VOICE=1.0）；播放结束 `finished` 释放引用（可被分级回收）。
- 小池复用（`VOICE_POOL_SIZE=3`，挂独立 Voice 总线），快速切行不频繁创建/销毁节点。
- 异步完成由 `ResourceManager` 的 `process_frame` 泵驱动（见 P6），AudioManager 自身无需 `_process`。

## 四、业务接线（对话系统）
- `services/dialogue/dialogue_service.gd`：`_render_line` 渲染数据新增可选字段 `voice`（取自对话 line 的 `voice` 字段，缺省空串）。
- `scenes/ui/overlays/dialog/DialogOverlay.gd`：`_render` 在 `voice != ""` 时调用 `AudioManager.play_voice(voice)`（缺省静默跳过，不卡对话推进）。
- 数据驱动：对话作者只需在某行写 `"voice": "res://resources/audio/voice/line_xxx.ogg"` 即触发异步语音，零代码改动。
