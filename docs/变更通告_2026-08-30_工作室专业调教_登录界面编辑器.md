## 一、本次改了什么

### 1. 新增「登录界面」标签页（用户需求：一键换登录界面大背景 + 各按钮背景 + 按钮文字对照 + 版本文字）

工具里新增一个 `登录界面` 标签页，覆盖**登录主界面（主菜单）及其打开的窗口**共用的资源。按用户选择 **「只做工具、不动游戏代码」**，全部走数据文件，进游戏即生效，不碰任何 GDScript。

四块功能：

| 区块 | 作用 | 落点文件 |
|---|---|---|
| 🖼 大背景图 | 选图→一键替换登录界面大背景；该图被**主菜单/加载/读档三场景共用**，换一次三处同变 | `assets/ui/main_menu_bg.jpg` |
| 🔤 按钮文字对照表 | 列出每个按钮的简/繁/英三语文案，直接改表保存；含「点击打开」列标注该按钮打开哪个窗口 | `data/configs/localization/strings.csv` |
| 🏷 版本文字 | 只读显示当前版本号（如 `v0.5.0 Build 20250827`，写在 `MainMenu.gd`）；用户选择不动代码故不可直接编辑 | — |
| 🎴 各按钮背景图（进阶） | 为 6 个主菜单大按钮各自配背景图，导入即按按钮 id 落盘并记录映射 | `assets/ui/main_menu_btn/<id>.png` + `data/configs/ui/login_button_bg.json` |

> ⚠️ 各按钮背景图目前**仅存盘、未在游戏内渲染**：游戏代码尚未读取 `login_button_bg.json`。要在游戏里真正显示，需在 `MainMenu.gd` 加约十几行读取并套用（低风险、会跑双闸门）。用户点头后再做。

### 2. 修复上一版 exe 双击报 `{"error":"file missing"}`

原因：上一次 PyInstaller 打包漏了 `--add-data "index.html;."`，导致 exe 内嵌服务找不到页面。本次用 `工作室专业调教.spec`（含 `datas=[('index.html','.')]`）重新打包，验证 `GET /` → HTTP 200、返回完整页面（35521 字节，含登录界面标签）。

### 3. 保险数据持久化（上一版已完成，本版沿用）

`--onefile` 模式临时目录退出即删，故保险/回收站/日志/设置改存 `AppData\Local\StudioProTool`，重启不丢。
