# 变更通告 2026-09-02 · 区域枢纽读条切换加载态优化

> 模块：战斗（场景切换体验）　改动范围：autoload/GameManager.gd + tests/unit/test_loading_overlay.gd　commit：（待提交后补）

## 变更项
1. **异步场景切换**：`goto_region` 改走 `_async_change_scene`（`ResourceLoader.load_threaded_request` 后台加载），`_process` 每帧轮询 `_poll_async_loading`，加载完成用已加载的 PackedScene 切换（`change_scene_to_packed`），避免二次加载；启动失败回退同步加载。
2. **loading 覆盖层**：GameManager 自建 CanvasLayer（层 600，高于系统浮层 500），全屏半透明底 + 居中提示文案（读 `data/configs/ui/loading_tips.json` 随机展示）+ 透明度呼吸动效。**不触碰 UI 窗口主权的 scenes/ui/** 文件**。
3. **相邻区域预加载**：进入区域后按 `regions.json` 的 connections 后台 `load_threaded_request` 预热相邻区域场景，未实装（scene_path 为空）或已缓存者跳过，切过去秒开。
4. **测试**：新增 `tests/unit/test_loading_overlay.gd` 5 项回归（覆盖层构建/清理/幂等/提示文案/预加载守卫）。

## 变更原因
世界区域枢纽式独立场景 + 读条切换，加载态可优化：原同步加载阻塞主线程、切换无反馈。改为异步加载 + 覆盖层动效 + 相邻区域预加载，提升切换手感与性能。

## 影响面
- **共享地基**：改动 `autoload/GameManager.gd`（场景切换统一由本单例驱动），已按铁律登记更改日志 + 本通告。
- **场景切换路径**：`goto_region` 现为异步加载，加载期间显示覆盖层；加载失败回退原同步路径，行为不变。
- **覆盖层层级**：层 600 高于 UIManager 系统浮层（SYSTEM_OVERLAY 500），确保读条期间遮挡所有界面；加载完成即移除。

## 回滚方案
- 恢复 `goto_region` 直接调用 `_deferred_change_scene`（同步路径），删除 `_async_change_scene`/`_poll_async_loading`/`_preload_adjacent_regions`/`_poll_preloads`/覆盖层相关函数与状态变量，删除 `test_loading_overlay.gd`。

## 协同方需知
- **UI 窗口**：覆盖层为 GameManager 自建，未改任何 scenes/ui/** 文件；层 600 高于系统浮层 500，读条期间会遮挡全屏（预期行为）。
- **其他窗口**：场景切换仍统一走 GameManager 驱动；`goto_region` 现在异步，若依赖「切换后立即访问新场景」需注意加载完成时机（`_poll_async_loading` 轮询收尾）。
- 相邻区域预加载依赖 `ConfigManager.get_region_connections`，新增区域时在 `regions.json` 填 `scene_path` 即自动纳入预加载。
- 双闸门：GATE1 零错；GATE2 本模块 5 项回归全过（当前全量套件受 UI 窗口 WIP test_responsive_anchor.gd 影响，见下）。
