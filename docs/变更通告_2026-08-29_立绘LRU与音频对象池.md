## 一、共享地基增量（纯追加，未改既有接口）

### 新增 `core/portrait_cache_manager.gd`（class_name PortraitCacheManager，全局静态工具）
- 立绘 LRU 缓存：解决 3000+ 立绘按需取用时的「重复加载 / 内存溢出 / 纹理不复用」三害。
- API：
  - `get_portrait(path) -> Texture2D`：UI 主路径。命中缓存 O(1) 直返；未命中同步加载并写入；path 空/不存在/加载失败返回 null（调用方按原逻辑降级）。
  - `preload_portrait(path)`：预热入缓存（对话开场先把主角/当前 NPC 立绘入缓存，避免首帧卡顿）。
  - `release_portrait(path)` / `clear()`：主动释放 / 全清（供场景大切换由 P6 全局资源管理器调用）。
  - `set_cap(n)`：运行时调整 LRU 上限（默认 50，可配）。
  - `get_cache_size()` / `has_portrait(path)`：诊断用。
- 设计：纯静态工具 + class_name 全局调用，**不注册新 Autoload、不碰既有共享地基**（对齐 icon_registry.gd 模式）。同一 path 全局只持有一份 Texture2D，所有 TextureRect 共享引用（纹理复用）。LRU 超出上限回收最久未用，内存有界。

### AudioManager（autoload，纯追加池化，未改对外签名）
- `play_sfx(path)` 重构为**播放器池复用**：原实现每次调用 `AudioStreamPlayer.new()` + `finished.connect(queue_free)`，频繁创建/销毁节点（内存碎片/残留风险）。
- 新增：`SFX_POOL_SIZE=8` 播放器池 + `_ensure_sfx_pool()`（挂独立 SFX 总线）+ `_next_sfx_player()`（优先空闲、全忙轮询复用）+ `_get_sfx_stream()`（path→AudioStream 流缓存，同一音效只 `load` 一次，零重复资源）。
- 调用方（`DialogueEventExecutor.play_sfx`）接口零变动。
