# 模块卡：门派（Sect）

> L2 模块卡 · 主权窗口：**门派窗口** · 沉淀自真实代码（据实不臆造）

- **职责**：加入门派、门派贡献、声望/阶位查询与持久化（当前门派、声望、阶位进存档）。
- **层定位**：服务层（`SectService` **有持久状态、实现 ISaveable**）+ 数据层（门派配置）+ UI 层（门派屏）。

## 关键文件
- 服务：`res://services/sect/sect_service.gd`（`class_name SectService`，**extends ISaveable**，有持久状态 `current_sect_id`/`reputation`/`rank`，存档 key=`"sect"`）
- UI 主权：`res://scenes/ui/screens/sect/SectScreen.gd`（screens.json `SectScreen`）
- 配置：`res://data/configs/sect/sects.json`

## 依赖（上游，它用到）
- `ConfigManager`：读 `sects.json`（门派/阶位阈值/贡献配置）
- `InventoryService`：入派扣道具（`join` 校验道具 → **见 BUG-07** 缺道具枚举语义）
- `GameManager.player_state`：声望/等级承载
- `EventBus` 信号：`cmd_join_sect(sect_id)` / `cmd_contribute_sect(sect_id,amount)`（**已声明未 emit**，空壳）

## 被依赖（下游，谁用它）
- `SectScreen.gd`（唯一直接驱动方：`join`/`contribute`/`get_reputation`/`get_rank`/`get_rank_name`）
- `GameManager.gd`（装配 `SectService.new()` + `register_saveable(sect_service)`）
- 单测：`tests/unit/test_sect_service.gd`（BUG-15 补测，`a44ddc4`）

## 对外 API（核心入口）
- `join(sect_id)→int`（扣道具+入派，返回 `SectEnums.JoinResult`）
- `contribute(sect_id,amount)→void`（加声望/推进阶位）
- `get_reputation(sect_id)→int` / `get_rank(sect_id)→int` / `get_rank_name(rank_value)→String`
- `get_save_key()→String` / `save()→Dictionary` / `load(data)→void` / `reset()→void`（ISaveable 契约）

## 架构备注
- **唯一实现 ISaveable 的经济/社交类服务**（有持久状态 `current_sect_id/reputation/rank`）；对比 shop/forge/alchemy 三者无状态、不进档——门派是「玩家成长态」服务，故需持久化。
- 入派走 `InventoryService` 事务扣道具（与商店/锻造/炼药同防资产损失范式）；枚举语义严格化（BUG-07）避免 UI 误报。
