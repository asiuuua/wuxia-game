# 模块卡：战斗（Combat）

> L2 模块卡 · 主权窗口：**战斗窗口** · 沉淀自真实代码（据实不臆造）

- **职责**：回合制 + 自动战斗内核（玩家普攻/技能/休息/用药、敌方 AI 行动、状态结算、网格走位与战术规划）、战斗发起/结算/奖励发放、战斗场景驱动。支持普通战（`BattleScene`）与战术战棋（`tactical_battle_scene`）。
- **层定位**：服务层（纯逻辑内核 `CombatCore` + 场景适配 `CombatService`）+ 数据层（运行时战斗状态/网格）+ 场景层（战斗场景驱动）。

## 关键文件
- 服务：`res://services/combat/combat_service.gd`（`class_name CombatService`，extends RefCounted，场景/UI 适配层，装配 `CombatCore`）、`res://services/combat/combat_core.gd`（`class_name CombatCore`，extends RefCounted，**纯逻辑战斗内核**，不依赖场景/节点）
- 运行时：`res://data/runtime/combat_state.gd`（`CombatState` 实例载体；`CombatCharacter`/`CombatEvent` 由 combat_core 内部定义）
- 网格：`BattleGrid` 由 `combat_service._build_grid()` 据 `battles.json` 构造（战术走位/可达域/技能射程计算）
- 场景主权（战斗窗口）：`res://scenes/gameplay/battle/BattleScene.gd`、`tactical_battle_scene.gd`、`battle_director.gd`（演出驱动）、`battle_view.gd`/`unit_hud.gd`/`battle_entity.gd`/`battle_grid_node.gd`
- 配置：`res://data/configs/scenes/battles.json`、`res://data/configs/battles/grids/preset_*.json`、`res://data/configs/battles/abilities/`、`res://data/configs/battles/npcs/`

## 依赖（上游，它用到）
- `ConfigManager`：读 `battles.json` / abilities / npcs / 网格预设
- `GameManager.player_state`：`_build_player_side` 据玩家属性建我方阵容
- `InventoryService` / `ItemInstance`：`player_use_item(instance_id)` 取道具实例生效（掉血/回蓝/解控等）
- `AbilityService`：`player_cast` 取技能（**见 BUG-19**：`use_combat_skill` 绕过 CombatCore 直调 `take_damage`/`mp` 有双重结算风险，已 `@deprecated`）
- `EventBus` 信号：`cmd_start_combat(attacker_list,defender_list)`（**唯一真接线**的 CMD 信号）、`combat_ended` / `combat_finished`（**见 BUG-32** 疑似语义重叠）

## 被依赖（下游，谁用它）
- 战斗场景三件套（`BattleScene` / `tactical_battle_scene` / `battle_director`）：唯一直接驱动方（`start_combat`→`player_*`/`run_enemy_turns`→`finalize`）
- 城镇/世界入口：TownScene 等触发 `cmd_start_combat` → `combat_service.start_combat`
- `GameManager.gd`：装配 `CombatService.new()`

## 对外 API（核心入口）
- 生命周期：`start_combat(battle_id)` / `is_over()` / `get_result()`（0胜1负2逃）/`finalize()`（发奖+清场）/ `try_escape()`
- 玩家行动：`player_attack(target_id)` / `player_cast(slot,target_id)` / `player_rest()` / `player_use_item(instance_id)` → `Dictionary`（事件列表封装）
- 敌方：`run_enemy_turns()` / `enemy_tactical_plan(enemy_id)→Dictionary`
- 网格/战术：`deploy_unit(unit_id,pos)` / `compute_reachable(unit_id)` / `compute_skill_range(caster_id,ability_id)` / `move_unit(unit_id,to_pos)` / `is_target_in_range(caster_id,target_id,ability_id)`
- 访问器：`get_state()` / `get_grid()` / `get_core()` / `get_grid_meta()`
- CombatCore 纯逻辑：`configure(p_state,seed)` / `player_basic` / `player_skill` / `enemy_phase` / `enemy_act` / `tick_unit` / `action_order()` / `get_round_sequence()` / `_resolve_hit` / `_apply_status`
