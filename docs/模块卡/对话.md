# 模块卡：对话（Dialogue）

> L2 模块卡 · 主权窗口：**对话窗口** · 沉淀自真实代码（据实不臆造）

- **职责**：NPC 对话图模型（台词分片懒加载+pin/unpin）、条件分支（has_item/quest_active/favor 等）、选项跳转、事件演出（sfx/shake/接任务/交任务）；对话屏驱动状态机。
- **层定位**：服务层（图+状态机）+ 数据层（台词分片/事件表）+ UI 层（对话覆盖层）。

## 关键文件
- 服务：`res://services/dialogue/dialogue_service.gd`（`class_name DialogueService`，extends RefCounted；深拷贝 lines+`__id` 索引、编译缓存 `_parsed_cache`、条件缓存 `_cond_cache` 1s TTL；状态机 `start/next/select_option/end`）
- 演出：`res://services/dialogue/dialogue_event_executor.gd`（`class_name DialogueEventExecutor`，extends RefCounted，订阅 `EventBus.dialogue_event_triggered`）
- 数据：`res://data/configs/npcs/dialogs/_index.json` + `res://data/configs/npcs/dialogs/shards/*.json`（台词分片）、`res://data/configs/dialogs/dialogue_events.json`（事件→效果表）
- 元数据：`ConfigManager.get_npc()` / `get_player()`（`res://data/configs/npcs/`）
- UI 主权：`res://scenes/ui/overlays/dialog/DialogOverlay.gd`（`.tscn`，screens.json `DialogOverlay`）

## 依赖（上游，它用到）
- `ConfigManager`：`get_dialog/has_dialog`、`resolve_for_npc`（npc_id→dialog_id 回退）、`get_npc/get_player`、`pin_dialog/unpin_dialog`（分片锁定）
- `EventBus` 信号（emit）：`dialogue_started(dialog_id,npc_id)`、`dialogue_ended(dialog_id)`、`dialogue_event_triggered(event_key)`
- 条件系统 `_eval_condition` **跨模块直取**（设计层 DI，见 BUG-16）：`GameManager.quest_service.is_active(arg)`、`GameManager.inventory_service.get_item_count(arg)`、`GameManager.bond_service.get_affection(_npc_id)`
- `DialogueEventExecutor` 依赖：`EventBus.dialogue_event_triggered`、`GameManager.quest_service.accept/complete_quest`、`AudioManager.play_sfx`、`GameManager.get_tree()`（震屏取相机）

## 被依赖（下游，谁用它）
- `DialogOverlay.gd`（唯一直接驱动方：start/next/select_option）
- `DialogueEventExecutor.setup()` 由 `GameManager` 装配时 connect；`teardown()` 热重载
- 间接：TownScene 等 NPC 交互入口 → `DialogOverlay._on_open` 经 UIManager 打开

## 对外 API（核心入口）
- `get_dialog(id)` / `has_dialog(id)` / `resolve_for_npc(npc_id,hint)→{dialog_id,lines}`
- `is_active()` / `get_npc_id()` / `get_dialog_id()`
- `start(npc_id,hint)→Dictionary`（首行渲染，命中编译缓存；emit `dialogue_started`）
- `next()→Dictionary` / `select_option(jump_id)→Dictionary` / `end()`
- `clear_cache()`（配置热重载）、`clear_condition_cache()`、`get_condition_cache_size()`
- `resolve_half_body(sid,is_player)→String`（立绘解析，供对话/欢庆/NPC 面板复用）
