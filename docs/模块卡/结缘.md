# 模块卡：结缘（Romance / Bond）

> L2 模块卡 · 主权窗口：**结缘窗口** · 沉淀自真实代码（据实不臆造）
> 模块代号 18（M1 好感 / M2 姻缘 / M3 关系网中枢 / M4 结义·师徒）

- **职责**：好感度与送礼（M1）、姻缘/婚姻/欢庆/婘眷值/子嗣（M2）、关系网数据中枢门面（M3）、结义（M4）、师徒（M4）。
- **层定位**：服务层（多服务 + 门面）+ 数据/枚举层 + UI 层（结缘屏/NPC 面板/欢庆覆盖层）。

## 关键文件
- 服务：`res://services/bond/bond_service.gd`（`class_name BondService`，extends ISaveable，key=`"bond"`，M1）、`romance_service.gd`（`class_name RomanceService`，extends ISaveable，key=`"romance"`，M2）、`sworn_service.gd`（`class_name SwornService`，extends ISaveable，key=`"sworn"`，M4）、`master_service.gd`（`class_name MasterService`，extends ISaveable，key=`"master"`，M4）、`relationship_service.gd`（`class_name RelationshipService`，extends RefCounted，M3 门面，不持状态不进档）
- 数据/枚举：`res://data/configs/bond/relations.json`、`special_portraits.json`、`celebrations.json`；`res://core/enums/bond_enums.gd`（`BondEnums`：AffectionLevel/GiftReaction/RomanceStage/WeddingType）
- UI 主权：`res://scenes/ui/screens/bond_romance/BondRomanceScreen.gd`（screens.json `BondRomance`）、`res://scenes/ui/screens/npc/NpcPanelScreen.gd`（screens.json `NpcPanel`，含婘眷值）、`res://scenes/ui/overlays/celebration/CelebrationOverlay.gd`（screens.json `CelebrationOverlay`）、`res://scenes/ui/overlays/hud/top_right_menu_panel.gd`（右上角姻缘红点）
