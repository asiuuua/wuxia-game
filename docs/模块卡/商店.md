# 模块卡：商店（Shop）

> L2 模块卡 · 主权窗口：**商店窗口** · 沉淀自真实代码（据实不臆造）

- **职责**：商店买卖定价与交易执行（买价/卖价计算、购买扣银两加物、售卖扣物加银两），库存查表（`_find_stock`），买卖可行性预检。
- **层定位**：服务层（无状态交易逻辑）+ 数据层（商店配置）+ UI 层（商店屏）。

## 关键文件
- 服务：`res://services/shop/shop_service.gd`（`class_name ShopService`，extends RefCounted，**无状态**，不实现 ISaveable）
- UI 主权：`res://scenes/ui/screens/shop/ShopScreen.gd`（screens.json `ShopScreen`）
- 配置：`res://data/configs/shop/shops.json`

## 依赖（上游，它用到）
- `ConfigManager`：读 `shops.json`（`_find_stock` 取库存/价格）
- `InventoryService`：买→`add_items` / 卖→`remove_item_by_id` + `get_unlocked_count`（**走背包事务防资产损失 P0**）
- `GameManager.player_state`：银两余额（`buy` 扣、`sell` 加）
- `EventBus` 信号：`cmd_buy(shop_id,item_id,count)` / `cmd_sell(shop_id,item_id,count)`（**已声明但未 emit**，空壳，交易实际由 ShopScreen 直调服务）

## 被依赖（下游，谁用它）
- `ShopScreen.gd`（唯一直接驱动方：`buy`/`sell`/`can_buy`/`can_sell`）
- `GameManager.gd`（装配 `ShopService.new()`）
- 单测：`tests/unit/test_shop_service.gd`（P2-A，5 项，含 BUG-04 核心回归）

## 对外 API（核心入口）
- `buy_price(shop_id,item_id)→int` / `sell_price(shop_id,item_id)→int`（定价）
- `buy(shop_id,item_id,count)→int`（扣银两+加物，返回实购数）
- `sell(shop_id,item_id,count)→int`（扣物+加银两，返回实售数）
- `can_buy(shop_id,item_id,count=1)→bool` / `can_sell(shop_id,item_id,count=1)→bool`（纯预检）
- `_find_stock(shop,item_id)→Dictionary`（内部库存查表）
