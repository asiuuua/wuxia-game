# 模块卡：背包（Inventory）

> L2 模块卡 · 主权窗口：**背包窗口** · 沉淀自真实代码（据实不臆造）

- **职责**：物品存储三栏（主背包 / 材料箱 / 任务栏），自动归类、堆叠、负重约束、锁定、拖拽排序、整理；装备抽离实例由 EquipmentService 接管。
- **层定位**：服务层（核心业务逻辑）+ 数据层（实例载体）+ UI 层（背包屏）。

## 关键文件
- 服务：`res://services/inventory/inventory_service.gd`（`class_name InventoryService`，extends ISaveable，存档 key=`"inventory"`）
- 事务：`res://services/inventory/inventory_transaction.gd`（`class_name InventoryTransaction`，extends RefCounted，批量 add/remove/consume 原子预校验+回滚）
- 装备（同窗口协作）：`res://services/equipment/equipment_service.gd`（`class_name EquipmentService`，extends ISaveable，key=`"equipment"`）
- 实例载体：`res://data/runtime/item_instance.gd`（`class_name ItemInstance`，instance_id/count/durability/locked）
- 数据/枚举：`res://data/schemas/item_data.gd`、`res://core/enums/item_enums.gd`（`ItemFlag`）、`res://core/constants/item_constants.gd`（`DEFAULT_MAX_SLOTS`/`BASE_MAX_WEIGHT`/`STRENGTH_WEIGHT_COEFF`）、`res://core/item_flags.gd`（`class_name ItemFlags`）
- UI 主权：`res://scenes/ui/overlays/inventory/InventoryScreen.gd`（`.tscn` 同目录，screens.json 注册名 `InventoryScreen`）、`res://scenes/ui/components/item_slot/ItemSlot.gd`

## 依赖（上游，它用到）
- `ConfigManager`：`has_item()` / `get_item()`（读 max_stack/weight/type/flags/equip_slot/durability/rarity）
- `EventBus` 信号（服务内 emit）：`inventory_item_added` / `inventory_item_removed` / `inventory_weight_changed(current,max)` / `inventory_add_overflow(item_id,lost_count)` / `item_used` / `item_used_in_battle`
- `GameManager.player_state`（真负重 `get_max_weight()` 读 `ps.strength`；用药 `heal/restore_mp`）
- `DifficultyManager`：`get_defeat_lose_rarities()` / `get_defeat_lose_include_material()` / `get_defeat_lose_include_quest()`（团灭丢物配置化）

## 被依赖（下游，谁用它）
- `GameManager.gd`（装配 `InventoryService.new()` + `register_saveable(inventory_service)`）
- `EquipmentService`（抽离/归还实例）、`ShopService`/`ForgeService`/`AlchemyService`（产出前 `can_add`/`query_add` 预检 + `add_items`/`try_consume`）
- `DialogueService`（`cond` `has_item` → `get_item_count`）、`BondService`/`RomanceService`（`consume_instance`/`get_instance_by_id`/`get_unlocked_count`/`remove_item_by_id`）
- `defeat_handler.gd`、`InventoryScreen.gd`、各 unit test

## 对外 API（核心入口）
- `add_item(item_id,count,source)` 自动归类入栏（堆叠+负重约束）；`add_items(items,source)` 批量事务添加（全装下才加）
- `add_instance(inst)` 原样归还实例（保 iid/耐久）
- `query_add(item_id,count)→{added,overflow}`、`can_add(item_id,count)` 纯计算预检
- `drop_item(iid,count)→{ok,reason,...}` 主动丢弃（校验 DISCARDABLE/锁定）
- `try_consume(items,source)` 原子扣料（尊重锁定，任一不足整体失败）
- `remove_item_by_id(id,count)` / `remove_instance(iid)` / `consume_instance(iid)`
- `use_item(instance_id,context)→Dictionary`（heal/buff/cure/exp 分发；battle 经 `item_used_in_battle`）
- `get_item_count(id)`（O(1) 缓存索引）、`get_unlocked_count(id)`、`get_locked_count(id)`
- `set_item_locked(iid,locked)` / `is_item_locked(iid)`
- `get_total_slots()/get_used_slots()/get_free_slots()/is_any_bag_full()/is_full()/get_free_capacity(bag_type)`
- `get_weight()` / `get_max_weight()`（=BASE+力量×系数）/`get_weight_ratio()` / `lose_some_non_rare_items(n)`
- `split_instance(iid,count)` / `move_instance(iid,target_bag,idx)`（拖拽排序）/ `sort_bag(name)`
- `reset()` / `get_save_key()` / `save()` / `load()`（保真槽位顺序 idx）
