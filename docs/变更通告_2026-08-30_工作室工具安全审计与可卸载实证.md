# 变更通告 · 工作室工具安全审计与可卸载实证

日期：2026-08-30
范围：`tools/desktop_studio/`（零代码工具，独立 Python 进程，与游戏运行时零进程耦合）

## 一、审计背景

应要求对「工作室专业调教」与项目的对接做全盘核实，结论分四块：

| 维度 | 结论 |
|---|---|
| 性能 | **无实质影响**。工具配置只在对应界面构建时读一次（几十 KB），不轮询、不每帧读 |
| 冗余 | **无运行时冗余**。`.gdignore` 隔离工具目录；游戏只读工具写出的 JSON，全部"缺失即回退"；游戏侧 4 处手写读 JSON 属模式重复，不强需收口（动共享地基，收益小） |
| 泄露 | **无对外暴露**。服务只绑 127.0.0.1；无任意文件读取路由；项目内无密钥；游戏本体尚未配置导出 |
| 安全 | **发现 5 个本地漏洞点**（本机可达，危害＝数据被篡改/文件被删），本轮全部修复（见下） |

## 二、本轮修复（5 项防护）

| # | 位置 | 漏洞 | 修复 |
|---|---|---|---|
| 1 | `studio_core.py` `_trash_path` | 回收站文件名未做 basename，`fn=../../x` 可穿出回收站删除/读取任意文件 | 统一 `os.path.basename` |
| 2 | `studio_core.py` `dlg_new/dlg_get/dlg_line_upsert/dlg_line_delete` | 对话 id 直接拼路径存文件，可穿越写 `.json` | 新增 `_is_valid_id()` 白名单（字母/数字/下划线/短横线），非法直接拒绝 |
| 3 | `studio_core.py` `login_btn_bg_set` | 按钮 id 直接拼文件名，可穿越写图 | 同上白名单 |
| 4 | `studio_core.py` `npc_portrait_import` | ZIP `extractall` 不校验条目（Zip Slip） | 解压前逐个校验条目名：拒绝对路径与含 `..`，并核验解压落点在目标目录内 |
| 5 | `studio_server.py` 全部 GET/POST/DELETE | 无 Origin/Referer 校验，恶意网页可向 127.0.0.1 接口发指令篡改数据（CSRF） | 统一 `_origin_allowed()`：仅放行无来源（curl/非浏览器）、`127.0.0.1/localhost`、`file://`/`null` |

- 恶意 POST 建对话 → 403 **且未写入任何文件** ✓

## 四、可卸载实证（工具配置全删，游戏仍绿）

临时移走 4 个"工具专属"配置文件（`login_button_bg.json` / `login_bg_layout.json` / `login_bg_variants.json` / `loading_layout.json`）后实测：

- GATE1（`--headless --quit`）：零 SCRIPT/PARSE/COMPILE ERROR ✓
- GATE2（`run_all.tscn`）：44 套件 · 失败 0 · ✗ 0 ✓
- 主菜单 / 预加载页实例化冒烟：正常，回退默认外观 ✓

**结论：`tools/desktop_studio/` 可整体删除；游戏运行时对其零依赖。** 其余 `data/configs/ui/` 文件（screens.json / ui_sfx.json / ui_anim.json / menu_config.json / loading_tips.json）属游戏基础配置，**不在可卸载范围**。

## 五、遗留提示（未在本轮处理，供后续决策）

1. **产品级脱节**：工具 exe 改的是源码目录 `data/**`，发行版游戏读的是打包内数据——工具里改了内容，需重打包（或用 Godot 编辑器运行）才能在游戏里看到。建议工具首页加一行提示。
2. **已知 BUG 留存**：休息/睡觉不推进天数（子嗣孕期不流逝）——原派单被"越权跳过"关闭，实际无人实现，建议重派。
3. 游戏侧 4 处手写"读 JSON + 缺省回退"可收口为统一读取器（收益小、需动共享地基，暂不做）。
