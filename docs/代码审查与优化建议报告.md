## 4. 核心功能链路（实测存在）

1. **启动链路**：project.godot → autoload 装配（GameManager 建 15 服务 + EventBus 信号 + ConfigManager 全量配置）→ MainMenu → start/load_game
2. **玩法链路**：TownScene(区域过滤生成 NPC，5969487) → NPC 交互 → DialogueService(条件/效果，ee282f1/bf2374f) → 接任务(前置门) → 战斗(cmd_start_combat) → combat_finished → quest_service 目标推进(handler 注册表) → 自动交付(then_set 回写) → 下一任务解锁
3. **存档链路**：ISaveable 注册 → SaveManager 原子写 + .bak 备份（216-225 行恢复逻辑）→ save_validator 校验 → 读档恢复
4. **工作室链路**：studio_launcher.bat → studio_server.py(单实例锁+8765) → index.html 前端 → /api/* → studio_core.py 读写 **区域表**（区域感知，P0-b 后唯一真源）→ 游戏 ConfigManager 同读一份 JSON（编辑器直写=即时生效）

**链路断点（遗留）**：读档后**固定回起始城镇**（读档点不记录区域/坐标——外部评估与本日复核一致，存档字段无 current_region/pos）。
